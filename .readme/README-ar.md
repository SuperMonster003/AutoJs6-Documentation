## مشاريع مرتبطة

[AutoJs4](https://github.com/SuperMonster003/AutoJs4) نسخة مستنسخة من آخر إصدار مفتوح المصدر لـ Auto.js وهو `4.1.1 Alpha2`. يحفظ المصدر الأصلي مع التحديثات اللازمة لبنائه وتشغيله على Android الحديث. وهو أيضا المرجع السلوكي لـ [AutoJs6](http://project.autojs6.com): باستثناء حالات محددة, يجب أن تعمل سكربتات AutoJs4 في AutoJs6 بنفس التأثير والنتيجة تماما. AutoJs6 أداة أتمتة JavaScript لـ Android مشتقة من Auto.js.

يحفظ [AutoJs4-Documentation](https://github.com/SuperMonster003/AutoJs4-Documentation) المصدر النهائي لتوثيق Auto.js `4.1.0`, وهو مرجع [AutoJs6-Documentation](http://docs-project.autojs6.com) (هذا المشروع). يحفظ AutoJs4 وتوثيقه التاريخ ويساعدان على مقارنة السلوك, بينما يواصل AutoJs6 وهذا التوثيق صيانة الواجهة الحالية.

## التطوير والنشر

`api/*.md` هو المصدر الوحيد لمحتوى التوثيق المتصل وغير المتصل. يتبع موقع Docsify فرع `master`; ويثبت `targetAutoJs6Version` في `project.json` إصدار محتوى HTML غير المتصل القابل لإعادة التوليد. بعد التحرير, يولد الأمر التالي جميع صفحات HTML ويطبق قواعد تطبيع الإضافة ويزامن بأمان إلى `AutoJs6-Plugin-Offline-Docs`. عند النجاح, يتطابق `versionName` لهذا المشروع وإصدار محتوى الإضافة مع `targetAutoJs6Version`, ويبقى إصدار الإضافة المستقل كما هو, ويزداد كل من `versionCode` / `VERSION_BUILD` بمقدار 1.

```powershell
generator\auto-generate-for-autojs6.bat
```

اضبط مسار الإضافة المحلي في `generator/local-config.json` غير المتتبع في Git; راجع [`generator/local-config.example.json`](http://docs-project.autojs6.com/blob/master/generator/local-config.example.json). يتطلب بناء الموقع Python 3.10+ و Node.js 16+ و npm.

ينشر `.github/workflows/pages.yml` مجلد `api/` مباشرة إلى GitHub Pages. اختر Source = `GitHub Actions` مرة واحدة في Pages Settings, ثم ثبّت تغييرات `master` وادفعها للتحديثات المعتادة, دون صيانة `gh-pages`. يظل النطاق `docs.autojs6.com` تحت إدارة Pages Settings. تحدث المزامنة شجرتي عمل محليتين فقط: راجع التوثيق المتصل وثبّت تغييراته هنا; وراجع التوثيق غير المتصل وثبّت تغييراته وأصدره بشكل مستقل في `AutoJs6-Plugin-Offline-Docs` وفق إجراءاته.

راجع [`generator/README.md`](http://docs-project.autojs6.com/blob/master/generator/README.md) لأوامر التوليد والفحص للقراءة فقط والبناء التزايدي والتحقق من الإضافة.
