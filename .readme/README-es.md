## Introducción

Documentación de [AutoJs6](http://project.autojs6.com), clonada de [hyb1996/AutoJs-Docs](https://github.com/hyb1996/AutoJs-Docs/). Plantillas, estilos y generador proceden de [Node.js](https://github.com/nodejs/node/tree/master/doc/). El sitio en línea y el complemento sin conexión comparten la misma fuente.

## Proyectos relacionados

[AutoJs4](https://github.com/SuperMonster003/AutoJs4) es un clon de la última versión abierta de Auto.js, `4.1.1 Alpha2`. Conserva el código original con los cambios necesarios para compilar y ejecutar en Android reciente. También sirve como referencia de comportamiento de [AutoJs6](http://project.autojs6.com): salvo casos específicos, los scripts que funcionan en AutoJs4 deben funcionar en AutoJs6 con los mismos efectos y resultados. AutoJs6 es una herramienta de automatización JavaScript para Android derivada de Auto.js.

[AutoJs4-Documentation](https://github.com/SuperMonster003/AutoJs4-Documentation) conserva la última fuente de documentación Auto.js `4.1.0` y sirve de referencia para [AutoJs6-Documentation](http://docs-project.autojs6.com) (este proyecto). AutoJs4 y sus documentos conservan la historia y permiten comparar comportamientos; AutoJs6 y esta documentación mantienen la API actual.

## Desarrollo y publicación

`api/*.md` es la única fuente del contenido en línea y sin conexión. Docsify sigue `master`; `targetAutoJs6Version` en `project.json` fija la versión reproducible del HTML sin conexión. Tras editar, el siguiente comando genera todo el HTML, aplica las reglas de normalización del complemento y sincroniza de forma segura con `AutoJs6-Plugin-Offline-Docs`. Si tiene éxito, `versionName` de este proyecto y la versión de contenido del complemento coinciden con `targetAutoJs6Version`; su versión independiente se conserva, y `versionCode` / `VERSION_BUILD` aumentan cada uno en 1.

```powershell
generator\auto-generate-for-autojs6.bat
```

Configure la ruta local del complemento en `generator/local-config.json`, no incluido en Git; consulte [`generator/local-config.example.json`](http://docs-project.autojs6.com/blob/master/generator/local-config.example.json). La generación del sitio requiere Python 3.10+, Node.js 16+ y npm.

`.github/workflows/pages.yml` despliega directamente `api/` en GitHub Pages. Seleccione Source = `GitHub Actions` una vez en Pages Settings y después confirme y envíe `master`; no hace falta mantener `gh-pages`. Pages Settings sigue gestionando `docs.autojs6.com`. La sincronización solo modifica dos árboles de trabajo locales: revise y confirme aquí la documentación en línea; revise, confirme y publique por separado la documentación sin conexión en `AutoJs6-Plugin-Offline-Docs` según su proceso.

Los comandos de generación, comprobación de solo lectura, compilación incremental y validación del complemento están en [`generator/README.md`](http://docs-project.autojs6.com/blob/master/generator/README.md).

## Documentación multilingüe

Este mecanismo traduce solo el README y el historial del repositorio; el sitio API conserva su idioma actual. Las fuentes README son `.readme/lang_*.json` y la plantilla `.readme/template_readme.md`; el README raíz usa chino simplificado. `api/changelog.md` sigue siendo el historial chino del sitio: sincronice sus cambios en `.changelog/lang_zh-Hans.json` y traduzca cada entrada a los otros 9 idiomas, conservando versiones, lotes fechados, orden y enlaces. No edite el Markdown generado. Estos comandos solo necesitan Python 3.10+, sin Node.js ni paquetes Python adicionales; Windows puede usar `py` en vez de `python`. `--check` no escribe archivos. La CI comprueba fuentes, sincronización y resultados en Ubuntu y Windows. Los generadores del sitio y del repositorio son independientes.

```shell
python .python/generate_markdown.py
python .python/generate_markdown.py --check
python -m unittest discover -s .python/tests
```
