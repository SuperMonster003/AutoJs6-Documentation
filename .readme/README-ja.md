## 概要

[AutoJs6](http://project.autojs6.com) のドキュメントで, [hyb1996/AutoJs-Docs](https://github.com/hyb1996/AutoJs-Docs/) から複製しました. テンプレート, スタイルと生成器は [Node.js](https://github.com/nodejs/node/tree/master/doc/) に由来します. オンラインサイトとオフライン文書プラグインは同じ内容ソースを使用します.

## 関連プロジェクト

[AutoJs4](https://github.com/SuperMonster003/AutoJs4) は Auto.js 最後のオープンソース版 `4.1.1 Alpha2` の複製です. 元のソースを保持し, 新しい Android でビルドと実行ができるよう必要な更新を行います. [AutoJs6](http://project.autojs6.com) の動作基準でもあり, 一部の例外を除き AutoJs4 で正常に動くスクリプトは AutoJs6 でも同じ効果と結果で動作する必要があります. AutoJs6 は Auto.js から派生した Android 向け JavaScript 自動化ツールです.

[AutoJs4-Documentation](https://github.com/SuperMonster003/AutoJs4-Documentation) は Auto.js `4.1.0` 文書の最終ソースを保存し, [AutoJs6-Documentation](http://docs-project.autojs6.com) (本プロジェクト) の参照基準になります. AutoJs4 とその文書は歴史保存と動作比較を担い, AutoJs6 と本書は現行 API を保守します.

## 開発と公開

`api/*.md` はオンライン/オフライン文書本文の唯一のソースです. Docsify サイトは `master` に追従し, `project.json` の `targetAutoJs6Version` が再現可能なオフライン HTML の内容バージョンを固定します. 編集後, 次のコマンドで全 HTML を生成し, プラグインの正規化規則を適用して `AutoJs6-Plugin-Offline-Docs` に安全に同期します. 成功時は本プロジェクトの `versionName` とプラグイン内容バージョンが `targetAutoJs6Version` に揃い, プラグイン独自のリリース版は維持され, 各 `versionCode` / `VERSION_BUILD` が 1 増加します.

```powershell
generator\auto-generate-for-autojs6.bat
```

プラグインのローカルパスは Git 管理外の `generator/local-config.json` に設定します. 例は [`generator/local-config.example.json`](http://docs-project.autojs6.com/blob/master/generator/local-config.example.json) を参照してください. サイト生成には Python 3.10+, Node.js 16+ と npm が必要です.

`.github/workflows/pages.yml` が `api/` を直接 GitHub Pages に公開します. Pages Settings の Source を一度 `GitHub Actions` に設定すれば, 通常は `master` のコミットとプッシュだけで更新でき, `gh-pages` の保守は不要です. 独自ドメイン `docs.autojs6.com` は Pages Settings で管理します. 同期は 2 つのローカル作業ツリーのみを更新します. オンライン文書は本リポジトリで確認してコミットし, オフライン文書は `AutoJs6-Plugin-Offline-Docs` で別途確認, コミットし, 同プラグインの手順で公開します.

生成, 読み取り専用検査, 増分ビルドとプラグイン検証は [`generator/README.md`](http://docs-project.autojs6.com/blob/master/generator/README.md) を参照してください.

## 注意事項と進捗

文書は随時更新され, 実際の動作と異なる説明が含まれる場合があります. 問題は本プロジェクトの [Issues](http://docs-project.autojs6.com/issues) に報告し, よくある質問は [Q & A](https://docs.autojs6.com/#/qa) を参照してください. `Auto.js 4.1.0` の文書を基に改善しており, [展開の進捗](https://docs.autojs6.com/#/progress) が遅い場合があります.

## 多言語ドキュメント

この仕組みはリポジトリの README と変更履歴のみを翻訳し, API サイトの言語は維持します. README のソースは `.readme/lang_*.json` と `.readme/template_readme.md` で, ルート README は簡体字中国語です. サイト履歴の中国語ソース `api/changelog.md` の変更を `.changelog/lang_zh-Hans.json` に同期し, バージョン, 日付の区分, 順序とリンクを保って他の 9 言語に各項目を翻訳します. 生成 Markdown は直接編集しません. 以下は Python 3.10+ のみで動作し, Node.js や追加 Python パッケージは不要です. Windows では `python` の代わりに `py` を使用できます. `--check` は書き込まず, CI が Ubuntu と Windows でソース, 履歴同期と生成物を検査します. サイト生成とリポジトリ文書生成は独立しています.

```shell
python .python/generate_markdown.py
python .python/generate_markdown.py --check
python -m unittest discover -s .python/tests
```
