## 관련 프로젝트

[AutoJs4](https://github.com/SuperMonster003/AutoJs4)는 Auto.js의 마지막 오픈 소스 버전 `4.1.1 Alpha2`를 복제한 프로젝트입니다. 원본 소스를 보존하며 최신 Android에서 빌드하고 실행하는 데 필요한 변경을 적용합니다. 또한 [AutoJs6](http://project.autojs6.com)의 동작 기준으로, 일부 예외를 제외하면 AutoJs4에서 정상 실행되는 스크립트는 AutoJs6에서도 동일한 효과와 결과를 내야 합니다. AutoJs6는 Auto.js에서 파생된 Android용 JavaScript 자동화 도구입니다.

[AutoJs4-Documentation](https://github.com/SuperMonster003/AutoJs4-Documentation)은 Auto.js `4.1.0` 문서의 최종 소스를 보존하며 [AutoJs6-Documentation](http://docs-project.autojs6.com) (현재 프로젝트)의 참조 기준입니다. AutoJs4와 해당 문서는 역사 보존과 동작 비교를 담당하고, AutoJs6와 이 문서는 현행 API를 유지합니다.

## 개발과 게시

`api/*.md`는 온라인/오프라인 문서 본문의 유일한 소스입니다. Docsify 사이트는 `master`를 따르며 `project.json`의 `targetAutoJs6Version`이 재현 가능한 오프라인 HTML 내용 버전을 고정합니다. 편집 후 아래 명령은 전체 HTML을 생성하고 플러그인의 정규화 규칙을 적용한 뒤 `AutoJs6-Plugin-Offline-Docs`에 안전하게 동기화합니다. 성공하면 본 프로젝트의 `versionName`과 플러그인 내용 버전은 `targetAutoJs6Version`과 일치하고 플러그인의 독립 출시 버전은 유지되며 각 `versionCode` / `VERSION_BUILD`는 1 증가합니다.

```powershell
generator\auto-generate-for-autojs6.bat
```

플러그인의 로컬 경로는 Git에서 제외된 `generator/local-config.json`에 설정합니다. 예제는 [`generator/local-config.example.json`](http://docs-project.autojs6.com/blob/master/generator/local-config.example.json)을 참조하세요. 사이트 생성에는 Python 3.10+, Node.js 16+와 npm이 필요합니다.

`.github/workflows/pages.yml`이 `api/`를 GitHub Pages에 직접 배포합니다. Pages Settings에서 Source를 한 번 `GitHub Actions`로 설정한 뒤 평소에는 `master`를 커밋하고 푸시하면 되며 `gh-pages` 유지가 필요 없습니다. 사용자 지정 도메인 `docs.autojs6.com`은 Pages Settings에서 관리합니다. 동기화는 두 로컬 작업 트리만 갱신합니다. 온라인 문서는 이 저장소에서 검토하고 커밋하며, 오프라인 문서는 `AutoJs6-Plugin-Offline-Docs`에서 별도로 검토, 커밋한 뒤 해당 플러그인의 절차로 출시합니다.

생성, 읽기 전용 검사, 증분 빌드와 플러그인 검증 명령은 [`generator/README.md`](http://docs-project.autojs6.com/blob/master/generator/README.md)을 참조하세요.

## 다국어 문서

이 기능은 저장소의 README와 변경 기록만 번역하며 API 사이트 언어는 유지합니다. README 소스는 `.readme/lang_*.json`과 `.readme/template_readme.md`이며 루트 README는 중국어 간체입니다. 사이트의 중국어 기록인 `api/changelog.md` 변경을 `.changelog/lang_zh-Hans.json`에 반영한 뒤 버전, 날짜별 묶음, 순서와 링크를 보존하여 다른 9개 언어로 항목마다 번역합니다. 생성된 Markdown을 직접 편집하지 마세요. 아래 명령은 Python 3.10+만 필요하며 Node.js나 추가 Python 패키지가 필요 없습니다. Windows에서는 `python` 대신 `py`를 사용할 수 있습니다. `--check`는 파일을 쓰지 않으며 CI는 Ubuntu와 Windows에서 소스, 기록 동기화와 결과를 검사합니다. 사이트 생성과 저장소 문서 생성은 독립적으로 실행됩니다.

```shell
python .python/generate_markdown.py
python .python/generate_markdown.py --check
python -m unittest discover -s .python/tests
```
