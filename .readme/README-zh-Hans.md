## 简介

[AutoJs6](http://project.autojs6.com) 应用文档, 克隆自 [hyb1996/AutoJs-Docs](https://github.com/hyb1996/AutoJs-Docs/). 模板, 样式及 Generator 来自 [Node.js](https://github.com/nodejs/node/tree/master/doc/). 在线站点与离线文档插件共用同一内容源.

## 关联项目

[AutoJs4](https://github.com/SuperMonster003/AutoJs4) 是 Auto.js 最终开源版本 `4.1.1 Alpha2` 的克隆项目, 保留原始源码, 并做必要更新使其可以正常构建并在新版 Android 中运行. 它也是 [AutoJs6](http://project.autojs6.com) 的行为基准: 除少数特定情况外, 能在 AutoJs4 正常运行的脚本, 在 AutoJs6 上也应正常运行且效果与结果完全一致. AutoJs6 是 Android 平台的 JavaScript 自动化工具, 是 Auto.js 的二次开发项目.

[AutoJs4-Documentation](https://github.com/SuperMonster003/AutoJs4-Documentation) 保留 Auto.js `4.1.0` 文档的最终源码, 并作为 [AutoJs6-Documentation](http://docs-project.autojs6.com) (当前项目) 的参考基准. AutoJs4 及其文档用于历史保留与行为对照; AutoJs6 及当前文档继续维护现行 API.

## 开发与发布

`api/*.md` 是在线与离线文档正文的唯一内容源. 在线 Docsify 站点随 `master` 更新; `project.json` 中的 `targetAutoJs6Version` 固定可复现的离线 HTML 内容版本. 编辑完成后, 以下命令全量生成离线 HTML, 应用离线插件规范化规则并安全同步到 `AutoJs6-Plugin-Offline-Docs`. 成功后, 本项目 `versionName` 与插件内容版本对齐 `targetAutoJs6Version`, 插件独立发行版本保持不变, 两个项目的 `versionCode` / `VERSION_BUILD` 各增加 1.

```powershell
generator\auto-generate-for-autojs6.bat
```

离线插件的本机路径在不纳入版本控制的 `generator/local-config.json` 中配置, 示例见 [`generator/local-config.example.json`](http://docs-project.autojs6.com/blob/master/generator/local-config.example.json). 文档站构建需要 Python 3.10+, Node.js 16+ 与 npm.

`.github/workflows/pages.yml` 直接将 `api/` 部署到 GitHub Pages. 在仓库 Pages Settings 中将 Source 设置为 `GitHub Actions` 后, 日常提交并推送 `master` 即可, 无需维护 `gh-pages`. 自定义域名 `docs.autojs6.com` 仍由 Pages Settings 管理. 同步脚本只更新两个本地工作树: 在线文档在本仓库审查并提交; 离线文档需在 `AutoJs6-Plugin-Offline-Docs` 中另行审查, 提交并按插件流程发版.

更多生成, 只读检查, 增量构建和插件校验命令参阅 [`generator/README.md`](http://docs-project.autojs6.com/blob/master/generator/README.md).

## 说明与进度

文档可能随时更新, 部分内容与实际代码行为可能存在出入. 问题可提交至本项目的 [Issues](http://docs-project.autojs6.com/issues), 常见问题参阅 [疑难解答](https://docs.autojs6.com/#/qa). 文档基于 `Auto.js 4.1.0` 修改完善, [部署进度](https://docs.autojs6.com/#/progress) 可能相对缓慢.

## 多语言文档

本机制仅翻译仓库 README 和更新日志, 不翻译 API 站点. README 文案源在 `.readme/lang_*.json`, 共用模板在 `.readme/template_readme.md`; 根目录 README 为简体中文. `api/changelog.md` 保持文档站中文历史来源, 将其变更同步到 `.changelog/lang_zh-Hans.json` 后逐条更新其他 9 种语言, 保留版本, 日期批次, 条目顺序和链接. 不直接编辑生成 Markdown. 以下命令只需 Python 3.10+, 不依赖 Node.js 或额外 Python 包; Windows 可用 `py` 替代 `python`. `--check` 不写文件, CI 在 Ubuntu 和 Windows 上检查源文件, 历史同步和生成产物. 文档站生成与仓库文档生成独立运行.

```shell
python .python/generate_markdown.py
python .python/generate_markdown.py --check
python -m unittest discover -s .python/tests
```
