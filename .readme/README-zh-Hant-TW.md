## 簡介

[AutoJs6](http://project.autojs6.com) 應用文件, 克隆自 [hyb1996/AutoJs-Docs](https://github.com/hyb1996/AutoJs-Docs/). 模板, 樣式及 Generator 來自 [Node.js](https://github.com/nodejs/node/tree/master/doc/). 線上站點與離線文件外掛共用同一內容源.

## 關聯專案

[AutoJs4](https://github.com/SuperMonster003/AutoJs4) 是 Auto.js 最終開源版本 `4.1.1 Alpha2` 的克隆專案, 保留原始原始碼, 並做必要更新使其可以正常構建並在新版 Android 中執行. 它也是 [AutoJs6](http://project.autojs6.com) 的行為基準: 除少數特定情況外, 能在 AutoJs4 正常執行的指令碼, 在 AutoJs6 上也應正常執行且效果與結果完全一致. AutoJs6 是 Android 平臺的 JavaScript 自動化工具, 是 Auto.js 的二次開發專案.

[AutoJs4-Documentation](https://github.com/SuperMonster003/AutoJs4-Documentation) 保留 Auto.js `4.1.0` 文件的最終原始碼, 並作為 [AutoJs6-Documentation](http://docs-project.autojs6.com) (當前專案) 的參考基準. AutoJs4 及其文件用於歷史保留與行為對照; AutoJs6 及當前文件繼續維護現行 API.

## 開發與釋出

`api/*.md` 是線上與離線文件正文的唯一內容源. 線上 Docsify 站點隨 `master` 更新; `project.json` 中的 `targetAutoJs6Version` 固定可復現的離線 HTML 內容版本. 編輯完成後, 以下命令全量生成離線 HTML, 應用離線外掛規範化規則並安全同步到 `AutoJs6-Plugin-Offline-Docs`. 成功後, 本專案 `versionName` 與外掛內容版本對齊 `targetAutoJs6Version`, 外掛獨立發行版本保持不變, 兩個專案的 `versionCode` / `VERSION_BUILD` 各增加 1.

```powershell
generator\auto-generate-for-autojs6.bat
```

離線外掛的本機路徑在不納入版本控制的 `generator/local-config.json` 中配置, 示例見 [`generator/local-config.example.json`](http://docs-project.autojs6.com/blob/master/generator/local-config.example.json). 文件站構建需要 Python 3.10+, Node.js 16+ 與 npm.

`.github/workflows/pages.yml` 直接將 `api/` 部署到 GitHub Pages. 在倉庫 Pages Settings 中將 Source 設定為 `GitHub Actions` 後, 日常提交併推送 `master` 即可, 無需維護 `gh-pages`. 自定義域名 `docs.autojs6.com` 仍由 Pages Settings 管理. 同步指令碼只更新兩個本地工作樹: 線上文件在本倉庫審查並提交; 離線文件需在 `AutoJs6-Plugin-Offline-Docs` 中另行審查, 提交併按外掛流程發版.

更多生成, 只讀檢查, 增量構建和外掛校驗命令參閱 [`generator/README.md`](http://docs-project.autojs6.com/blob/master/generator/README.md).

## 多語言文件

本機制僅翻譯倉庫 README 和更新日誌, 不翻譯 API 站點. README 文案源在 `.readme/lang_*.json`, 共用模板在 `.readme/template_readme.md`; 根目錄 README 為簡體中文. `api/changelog.md` 保持文件站中文歷史來源, 將其變更同步到 `.changelog/lang_zh-Hans.json` 後逐條更新其他 9 種語言, 保留版本, 日期批次, 條目順序和連結. 不直接編輯生成 Markdown. 以下命令只需 Python 3.10+, 不依賴 Node.js 或額外 Python 包; Windows 可用 `py` 替代 `python`. `--check` 不寫檔案, CI 在 Ubuntu 和 Windows 上檢查原始檔, 歷史同步和生成產物. 文件站生成與倉庫文件生成獨立執行.

```shell
python .python/generate_markdown.py
python .python/generate_markdown.py --check
python -m unittest discover -s .python/tests
```
