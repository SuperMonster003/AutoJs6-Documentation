# 国际化 (Internationalization)

---

`i18n` 是基于内置 `banana-i18n` 模块的本地化函数对象. 它从 JSON 文件或 JavaScript 对象加载不同区域设置的消息, 并按当前区域设置完成消息查找和参数替换.

脚本运行时会自动执行 `i18n.loadAll()` 并将当前区域设置设为 `default`. 默认消息目录为 `i18n`; 如果该相对路径不是目录, [i18n.getPath](#m-getpath) 会尝试使用 `assets/i18n`.

```text
project/
|-- main.js
`-- i18n/
    |-- default.json
    `-- zh-CN.json
```

`i18n/zh-CN.json`:

```json
{
  "welcome": "你好, $1!"
}
```

`main.js`:

```js
i18n.setLocale('zh-CN');
console.log(i18n('welcome', 'AutoJs6')); // 你好, AutoJs6!
```

> `i18n` 的消息语法, 复数规则及回退规则由内置 `banana-i18n` 实现.

## [@] i18n

### i18n(key, ...parameters)

**`Global`**

- **key** { [string](dataTypes#string) } - 消息键
- **...parameters** { [...](documentation#可变参数)[any](dataTypes#any)[[]](documentation#可变参数) } - 消息替换参数

按当前区域设置查找并格式化消息. `i18n` 是可调用对象, 同时包含本章列出的属性和方法.

## [m] load

### load(messageSource, locale)

**`Overload 1/2`**

- **messageSource** { [Object](dataTypes#object) } - 消息键值对象
- **locale** { [string](dataTypes#string) } - 消息所属的区域设置
- <ins>**returns**</ins> { [void](dataTypes#void) }

把消息对象加载到底层消息存储.

```js
i18n.load({
    greeting: 'Hello, $1!',
}, 'en');
i18n.setLocale('en');
console.log(i18n('greeting', 'AutoJs6'));
```

### load(messageSource, locale?)

**`Overload 2/2`**

- **messageSource** { [string](dataTypes#string) } - 区域设置名称或 JSON 文件路径
- **[ locale ]** { [string](dataTypes#string) } - 消息所属的区域设置
- <ins>**returns**</ins> { [void](dataTypes#void) }

从 JSON 文件加载消息.

- **messageSource** 不含系统路径分隔符时, 文件解析为 `<消息目录>/<messageSource>.json`.
- **messageSource** 含系统路径分隔符时, 将其作为文件路径解析.
- 省略 **locale** 时, 同时使用 **messageSource** 作为区域设置标识.

文件不存在, 文件不是普通文件或 JSON 解析失败时抛出异常. JSON 解析失败时还会向控制台写入警告.

## [m] loadAll

### loadAll()

- <ins>**returns**</ins> { [void](dataTypes#void) }

加载消息目录第一层的全部 `.json` 文件. 每个文件的不含扩展名部分作为区域设置标识. 此方法不会递归扫描子目录.
