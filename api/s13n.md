# 标准化 (Standardization)

s13n 模块用于将多种不同类型的数据统一转换为标准类型.

例如在 AutoJs6 中, 一个颜色参数通常可接受 [ [ColorHex](dataTypes#colorhex) / [ColorInt](dataTypes#colorint) / [ColorName](dataTypes#colorname) / [Color](colorType) / [ThemeColor](dataTypes#themecolor) ] 等多种类型:

```js
console.setBackgroundColor('orange');
console.setBackgroundColor('#663399');
console.setBackgroundColor(autojs.themeColor);
console.setBackgroundColor(Color('blue').setAlpha(0.75));
```

上述这些颜色设置方式均有效.<br>
但安卓 API 中涉及颜色的参数往往只接受 `ColorInt` 类型:

```js
activity.window.setStatusBarColor('orange'); /* 抛出异常. */
activity.window.setStatusBarColor(Color('orange')); /* 抛出异常. */
activity.window.setStatusBarColor(Color('orange').toInt()); /* 正常. */
activity.window.setStatusBarColor(colors.toInt('orange')); /* 效果同上. */
```

上述示例的颜色参数只能使用 `ColorInt`, 对应 JavaScript 的 `number` 类型.

s13n 模块对颜色参数统一转换为 `ColorInt`:

```js
s13n.color('red'); /* 相当于 colors.toInt('red'). */
```

因此对于上述设置通知栏颜色的示例, 使用 s13n 模块即可不必关心参数原本的类型:

```js
activity.window.setStatusBarColor(s13n.color('orange')); /* 正常. */
activity.window.setStatusBarColor(s13n.color(Color('orange'))); /* 正常. */
activity.window.setStatusBarColor(s13n.color(Color('orange').toInt())); /* 正常. */
activity.window.setStatusBarColor(s13n.color(Color('orange').toHex())); /* 正常. */
```

AutoJs6 内置 API 通常会在实现中自行完成参数标准化. 例如 `console.setBackgroundColor` 会将颜色参数交给 `s13n.color` 转换, 因此调用这些 API 时通常不需要预先调用 s13n.

下表列出了 s13n 模块中不同方法接受类型与输出类型:

| 方法名称 | 描述 | 输出类型 |
|---|---|---|
| [bytes](#m-bytes) | 字节数 | [number](dataTypes#number) 或 [bigint](glossaries#bigint) |
| [color](#m-color) | 颜色 | [ColorInt](dataTypes#colorint) |
| [point](#m-point) | 坐标点 | [android.graphics.Point](https://developer.android.com/reference/android/graphics/Point) |
| [throwable](#m-throwable) | 可抛异常 | [java.lang.Throwable](exceptions#java) |
| [time](#m-time) | 时间值 | [number](dataTypes#number) |

## [m] color

### color(o)

- **o** { [OmniColor](omniTypes#omnicolor) }
- <ins>**returns**</ins> { [ColorInt](dataTypes#colorint) }

将颜色参数 `o` 标准化为 [ColorInt](dataTypes#colorint).

```js
s13n.color('red') === s13n.color('#F00'); // true
s13n.color('#FB663399') === s13n.color(0xFB663399); // true
```

## [m] point

### point(source, y?)

**`6.6.0`**

- **source** { [android.graphics.Point](https://developer.android.com/reference/android/graphics/Point) | [OpenCVPoint](opencvPointType) | [number](dataTypes#number)[] | {{ x: [number](dataTypes#number); y: [number](dataTypes#number) }} | [number](dataTypes#number) } - 坐标点参数或 X 坐标
- **[ y ]** { [number](dataTypes#number) } - Y 坐标
- <ins>**returns**</ins> { [android.graphics.Point](https://developer.android.com/reference/android/graphics/Point) } - Android 坐标点

将坐标参数标准化为 `android.graphics.Point`.

当 **source** 为单个数值且省略 **y** 时, X 和 Y 坐标均采用 **source**.

```js
s13n.point([ 10, 20 ]);
s13n.point({ x: 10, y: 20 });
s13n.point(10, 20);
s13n.point(10); // Point(10, 10)
```

## [m] time

### time(source, fromUnit?, toUnit?)

**`6.6.0`**

- **source** { [number](dataTypes#number) | [string](dataTypes#string) | [Date](dataTypes#date) } - 时间值
- **[ fromUnit ]** { [string](dataTypes#string) | [java.util.concurrent.TimeUnit](https://docs.oracle.com/javase/8/docs/api/java/util/concurrent/TimeUnit.html) | {{ fromUnit?: [string](dataTypes#string); toUnit?: [string](dataTypes#string) }} } - 源单位或选项对象
- **[ toUnit ]** { [string](dataTypes#string) | [java.util.concurrent.TimeUnit](https://docs.oracle.com/javase/8/docs/api/java/util/concurrent/TimeUnit.html) } - 目标单位
- <ins>**returns**</ins> { [number](dataTypes#number) } - 标准化或换算后的时间值

标准化时间值并按需进行单位换算. 源单位和目标单位默认均为毫秒.

字符串单位不区分大小写, 支持纳秒, 微秒, 毫秒, 秒, 分钟, 小时和天的常用英文名称及缩写. 包含年, 月, 日, 时, 分, 秒 6 个数值部分的日期时间字符串会先转换为时间戳.

```js
s13n.time(2, 'seconds'); // 2000
s13n.time(120000, { fromUnit: 'ms', toUnit: 'minutes' }); // 2
s13n.time(new Date()); // 当前时间戳.
```

## [m] bytes

### bytes(source, fromUnit?)

**`6.7.0`**

- **source** { [number](dataTypes#number) | [string](dataTypes#string) } - 字节数值, 字符串可包含单位
- **[ fromUnit ]** { [string](dataTypes#string) } - 源单位, 默认为 `B`
- <ins>**returns**</ins> { [number](dataTypes#number) | [bigint](glossaries#bigint) } - 换算后的整数 Byte 数

将字节单位参数标准化为 Byte 数. 单位解析规则与 [cvt.bytes](cvt#m-bytes) 的宽松模式一致.

```js
s13n.bytes('1.5 KiB'); // 1536
s13n.bytes(2, 'MB'); // 2097152
```

## [m] throwable

### throwable(o)

- **o** { [OmniThrowable](omniTypes#omnithrowable) }
- <ins>**returns**</ins> { [java.lang.Throwable](exceptions#java) }

将可抛异常参数 `o` 标准化为 [java.lang.Throwable](exceptions#java) 类型.

```js
let a = s13n.throwable('error message');
let b = s13n.throwable(Error('error message'));
let c = (/* @IIFE */ () => {
    try {
        nothing++;
    } catch (e) {
        return s13n.throwable(e.rhinoException);
    }
})();

[ a, b, c ].every(o => o instanceof java.lang.Throwable); // true
```
