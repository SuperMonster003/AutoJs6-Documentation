# Android XML 属性 (Android XML Attributes)

本章介绍 AutoJs6 如何应用原生 Android XML 布局 (参阅 [布局转换模式](ui#布局转换模式)) 中的属性, 并按类列出属性的支持情况. AutoJs6 简写布局的属性参阅 [UI 布局属性](uiAttributes).

AutoJs6 不使用 Android 平台的 `LayoutInflater`. 视图创建时不带 `AttributeSet`, 属性在视图创建后逐个设置, 因此只能在构造时读取的属性无法生效. 能通过公开 API 设置的属性都会设置, 无法设置的属性会明确告知.

## 应用顺序

每个属性按以下顺序处理, 第一个接受该属性的方式生效:

- 处理器: AutoJs6 为常用视图编写的属性处理器. 简写布局与原生布局共用这些处理器.
- 创建期属性: `style`, `android:theme`, `<view>` 的 `class`, 以及 `Spinner`, `DatePicker`, `TimePicker` 的模式在创建视图时读取.
- 公开方法: 属性元数据 (Android SDK 与 AutoJs6 自带的 AndroidX / Material 库) 中该类或其父类声明的属性, 以视图的公开单参方法设置. 方法按命名规则查找 (如 `set<Name>`, `set<Name>TintList`, `setMinimum<Name>`, 比较时忽略大小写), 参数类型按属性格式选择 (颜色优先 `ColorStateList`, 引用优先 `Drawable`, 尺寸优先 `float`); 少数需要多个参数或特殊转换的属性 (如 `layerType`, `digits`, `textLocale`, Toolbar 的 `contentInsetStart`) 单独处理.
- 布局参数: 父容器布局参数 (`LayoutParams`) 的公开字段或方法, 如 ConstraintLayout 的约束, CoordinatorLayout 的 `layout_behavior` 与 `layout_anchor`, AppBarLayout 的 `layout_scrollFlags`, GridLayout 的行与列.

取值的转换与处理器一致: 尺寸, 颜色, 颜色状态列表, Drawable, ID, 字符串与数组可使用工程资源 (参阅 [工程资源](ui#工程资源)), 枚举与标志使用属性元数据中的名称, 标志可用 `|` 组合.

属性按书写顺序应用, 后写的覆盖先写的, 如 `padding` 之后的 `paddingHorizontal`. 例外: `ImageView` 的 `adjustViewBounds` 总是先于 `scaleType` 应用, 与平台一致.

## 不支持与未知的属性

- 原生 XML 中, 无法设置的属性 (属性元数据中有, 但没有可用的公开方法, 或高于当前 Android 版本) 与未知属性 (属性元数据中没有, 多为拼写错误) 被跳过, 脚本控制台按 "类与属性" 警告一次, 布局继续.
- 样式与主题中视图不接受的属性被静默忽略, 与 Android 一致.
- `tools:` 等其他命名空间的属性, 以及 `layout_editor_*` 等设计期属性被忽略.
- AutoJs6 简写布局保持原有行为: 未知属性被静默忽略, 处理器声明不支持的属性使布局失败.

## 命名空间与别名

- `android:`, `app:` 与无前缀的属性使用同一组处理器. 库未声明某个 `app:` 属性时, 按同名的 `android:` 属性查找.
- `app:srcCompat` 与 `app:drawableStartCompat` 等 AppCompat 属性按对应的平台属性 (`android:src`, `android:drawableStart` 等) 应用.

## Material 组件

`com.google.android.material` 中的组件要求 Material 主题. 当前主题不是 Material 主题时 (如 UI 模式的默认主题), AutoJs6 以 Material 3 主题补齐缺少的主题属性, 已有的主题属性 (如 `colorPrimary`) 保持不变. 需要完整的 Material 外观时, 可为布局指定 `android:theme`.

## ConstraintLayout

- 约束, 偏移, 链样式, 尺寸约束与 Guideline 等子视图参数按 ConstraintLayout 的布局参数设置.
- ConstraintLayout 自身的 `android:maxWidth` 与 `app:layout_optimizationLevel` 等属性, 以及 `Barrier`, `Group`, `Flow` 等辅助类的 `app:barrierDirection`, `app:constraint_referenced_ids` 与 `app:flow_*` 等属性按各自的公开方法设置.
- `app:constraintSet` 与 `app:layoutDescription` 需要编译后的 XML, 不受支持.
