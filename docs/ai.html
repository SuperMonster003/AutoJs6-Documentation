人工智能 (AI)#

ai 模块用于通过已配置的 AI 提供商发起文本生成, 对话和流式请求.

ai 与 $ai 指向同一个可调用模块对象.

使用基于配置档案的调用前, 需要先在 AutoJs6 的 AI 提供商设置中创建可用档案. 也可在单次请求中显式提供 provider, model 和凭据等选项.

ai

[@] ai#

ai(input, options?)#

6.8.0 Async Overload [1-2]/2

  • input { string | AiMessage | AiMessage[] | AiRequest } - 提示词, 消息或完整请求
  • [ options = {} ] { AiOptions } - 请求选项
  • returns { Promise } - 兑现值为生成文本

发起文本生成请求.

此调用与 ai.ask(input, options?) 等价.

ai('Reply with OK').then((text) => {
    console.log(text);
});

[m] ask#

ask(input, options?)#

6.8.0 Async Overload [1-2]/2

  • input { string | AiMessage | AiMessage[] | AiRequest } - 提示词, 消息或完整请求
  • [ options = {} ] { AiOptions } - 请求选项
  • returns { Promise } - 兑现值为 string 类型的生成文本

发起非流式请求, 并仅返回响应中的文本结果.

[m] chat#

chat(input, options?)#

6.8.0 Async Overload [1-2]/2

  • input { string | AiMessage | AiMessage[] | AiRequest } - 提示词, 消息或完整请求
  • [ options = {} ] { AiOptions } - 请求选项
  • returns { Promise } - 兑现值为 AiResponse

发起非流式请求, 并返回提供商无关的完整响应.

返回对象中的 message 可在使用同一提供商时追加到后续消息数组, 以保留工具调用和提供商专用数据.

let messages = [
    { role: 'user', content: 'Return one short greeting' },
];

ai.chat(messages).then((response) => {
    console.log(response.text);
    console.log(response.usage);
});

[m] stream#

stream(input, options?)#

6.8.0 Async Overload [1-2]/2

  • input { string | AiMessage | AiMessage[] | AiRequest } - 提示词, 消息或完整请求
  • [ options = {} ] { AiOptions } - 请求选项
  • returns { AiStream } - 流式请求对象

发起流式请求并立即返回事件对象.

let stream = ai.stream('Count from 1 to 3');

stream
    .on('delta', (text) => {
        console.log(text);
    })
    .on('done', (response) => {
        console.log(response.finishReason);
    })
    .on('error', (error) => {
        console.error(error.message);
    });

请求输入#

AiMessage#

AiMessage 是可进行 JSON 序列化的消息对象.

  • role { string } - 消息角色
  • content { any } - 消息内容

常用角色为 system, developer, user, assistant 和 tool. 具体支持范围由所选提供商协议决定.

消息可包含提供商原生字段. 工具结果消息还可使用 toolCallId, tool_call_id, toolUseId, tool_use_id 或 id 指定对应工具调用.

AiRequest#

  • messages { AiMessage[] } - 非空消息数组
  • options { AiOptions } - 除 messages 外的内联请求选项

AiRequest 是至少包含 messages 属性的可进行 JSON 序列化对象. messages 之外的属性会作为内联 AiOptions.

当同时传入第二个 options 参数时, 第二个参数中的同名属性覆盖内联选项.

以下输入会被转换为消息数组:

  • 字符串转换为一条 role 为 user 的消息.
  • 单个包含 role 和 content 的对象转换为单元素消息数组.
  • 数组直接作为消息数组.
  • 包含 messages 的对象使用其 messages 属性.

输入必须可由 JSON.stringify 序列化, 消息数组不能为空.

AiOptions#

以下属性由 ai 模块直接处理:

  • [ profile ] { string } - 档案 ID 或名称
  • [ provider ] { string } - 提供商 ID
  • [ baseUrl ] { string } - 服务基础 URL
  • [ model ] { string } - 模型名称
  • [ apiKey ] { string } - 仅用于本次请求的 API 密钥
  • [ timeout ] { number } - 请求超时, 单位为毫秒

兼容属性名称:

  • profile: profileId, profile_id.
  • provider: providerId, provider_id.
  • baseUrl: baseURL, base_url.
  • apiKey: api_key.
  • timeout: timeoutMillis, timeoutMs, timeout_millis.

timeout 必须是 1000..600000 范围内的整数.
ask 和 chat 的默认超时为 120000 毫秒.
stream 的默认超时为 600000 毫秒.

未指定 profile 和 provider 时使用默认档案.
指定 profile 时按档案 ID 或名称选择档案.
仅指定 provider 时按提供商选择档案.

不依赖已保存档案的独立调用至少需要 provider 和 model. 通常还需要 apiKey.
仅当 openai-compatible 使用严格的本机回环地址时, 才允许省略 API 密钥.

以下提供商无关的请求属性会映射到对应提供商协议:

  • [ system ] { any } - 系统指令
  • [ temperature ] { number } - 采样温度
  • [ maxTokens ] { number } - 最大输出 token 数
  • [ topP ] { number } - top-p 采样参数
  • [ topK ] { number } - top-k 采样参数
  • [ stopSequences ] { string | string[] } - 停止序列
  • [ tools ] { any[] } - 工具定义
  • [ toolChoice ] { any } - 工具选择策略

提供商原生请求属性也会保留. 当原生属性与提供商无关别名同时存在时, 原生属性优先.

headers, callbacks, signal, abortSignal, returnRaw, raw 以及 onText 等回调属性不会转发到提供商.

返回对象#

AiResponse#

  • text { string } - 生成文本
  • reasoning { string } - 推理文本, 不可用时为空字符串
  • toolCalls { AiToolCall[] } - 工具调用
  • usage { AiUsage | null } - token 用量
  • finishReason { string | null } - 完成原因
  • message { Object | null } - 提供商原生 assistant 消息
  • error { AiProviderError | null } - 响应内错误
  • raw { any } - 提供商原始响应
  • profile { AiProfileReference } - 本次请求使用的档案信息
  • provider { string } - 提供商 ID
  • model { string } - 模型名称

AiStreamChunk#

  • text { string } - 当前增量文本
  • reasoning { string } - 当前增量推理文本
  • toolCalls { AiToolCall[] } - 当前增量工具调用
  • usage { AiUsage | null } - 当前用量信息
  • finishReason { string | null } - 完成原因
  • done { boolean } - 是否为终止块
  • raw { any } - 提供商原始数据

AiToolCall#

  • index { number | null } - 工具调用序号
  • id { string | null } - 工具调用 ID
  • name { string | null } - 工具名称
  • arguments { string | null } - JSON 参数或参数增量
  • argumentsAreDelta { boolean } - arguments 是否为增量片段
  • raw { any } - 提供商原始工具调用数据

AiUsage#

  • inputTokens { number | null } - 输入 token 数
  • outputTokens { number | null } - 输出 token 数
  • totalTokens { number | null } - token 总数
  • reasoningTokens { number | null } - 推理 token 数
  • cachedInputTokens { number | null } - 缓存输入 token 数
  • raw { Object | null } - 提供商原始用量数据

AiProviderError#

  • type { string | null } - 提供商错误类型
  • code { string | null } - 提供商错误代码
  • message { string | null } - 提供商错误消息

AiProfileReference#

  • id { string | null } - 档案 ID
  • name { string | null } - 档案名称
  • provider { string } - 提供商 ID
  • baseUrl { string } - 服务基础 URL
  • model { string } - 模型名称

独立调用没有已保存档案, 因此 id 和 name 为 null.

AiProfile#

  • id { string } - 档案 ID
  • name { string | null } - 档案名称
  • provider { string | null } - 提供商 ID
  • baseUrl { string | null } - 服务基础 URL
  • model { string | null } - 模型名称
  • hasApiKey { boolean | null } - 是否保存了 API 密钥
  • isDefault { boolean } - 是否为默认档案
  • status { 'available' | 'unavailable' } - 档案是否可用
  • errorCode { 'missing_entry' | 'decryption_failed' | 'invalid_data' | null } - 档案不可用原因代码

无法解密或解析的档案仍会出现在列表中, 此时部分字段为 null.

AiProvider#

  • id { string } - 提供商 ID
  • defaultBaseUrl { string | null } - 默认服务基础 URL

AiStream#

  • extends { EventEmitter }

AiStream 是单次流式 AI 请求的事件对象.

它继承 EventEmitter 的 addListener, eventNames, listenerCount, listeners, prependListener, prependOnceListener, removeAllListeners, removeListener 和 setMaxListeners 等方法.

[p#] AiStream#state#

6.8.0 READONLY

  • { 'created' | 'open' | 'done' | 'error' | 'cancelled' }

当前流状态.

[p#] AiStream#isDone#

6.8.0 READONLY

  • { boolean }

流是否已经结束.

[m#] AiStream#on(eventName, listener)#

6.8.0

  • eventName { string } - 事件名称
  • listener { Function } - 事件监听器
  • returns { AiStream } - 当前流对象

注册持续事件监听器.

[m#] AiStream#once(eventName, listener)#

6.8.0

  • eventName { string } - 事件名称
  • listener { Function } - 单次事件监听器
  • returns { AiStream } - 当前流对象

注册仅执行一次的事件监听器.

[m#] AiStream#cancel()#

6.8.0

  • returns { AiStream } - 当前流对象

取消网络请求并终止流.

重复调用不会再次取消. 成功接受取消操作后触发 cancelled 事件.

AiStream 事件#

事件监听器参数:

事件 监听器参数 说明
open profile { AiProfileReference } 请求已打开
delta text { string }, chunk { AiStreamChunk } 收到文本或推理增量
chunk chunk { AiStreamChunk } 收到提供商响应块
toolCall toolCall { AiToolCall } 收到工具调用或工具调用增量
usage usage { AiUsage } 收到用量信息
done response { AiResponse } 流正常完成
error error { AiStreamError } 流失败
cancelled 无 流被调用方取消

delta 的 text 参数对应 chunk.text. 当事件只包含推理增量时, text 可能为空字符串, 此时使用 chunk.reasoning.

AiStreamError#

  • name { string } - 异常类名称
  • message { string } - 错误消息
  • [ provider ] { string } - 提供商 ID
  • [ statusCode ] { number } - HTTP 状态码
  • [ code ] { string | null } - 提供商错误代码
  • [ type ] { string | null } - 提供商错误类型
  • [ requestId ] { string | null } - 提供商请求 ID

只有 HTTP 提供商错误包含 provider, statusCode, code, type 和 requestId.
