文档更新日志 (Changelog)#

v6.8.0#

  • 新增 ImGui 的完整参考: 快速开始, 会话与窗口模式, 调用时机, 单位, 线程, 错误与限制, 全部函数与常量组, PascalCase 别名表, 以及 ImguiSession, ImguiDrawList, ImguiFloatingButton, ImguiComponent, ImguiDataTable, ImguiLogWindow, ImguiToast, ImguiStatsOverlay, ImguiDialog, ImguiDialogPromise, ImguiTexture, ImguiSelectionStorage 与 ImguiMultiSelectIO 对象页, 内容对应 ImGui 插件 1.18.0, 页面已加入侧栏与目录

  • 新增 语音 (Speech) 的模型更新说明, SpeechModelInfo 增加 updateAvailable 与 latestVersionCode (3-Macaw Speech 1.4.0 及以上)

  • 更新 ImGui: 运行时支持表标明 Node.js 与 Bun 不提供 imgui 模块, 新增 在 Node.js / Bun 中使用: 用 engines.execScript 启动 Rhino 脚本打开窗口, 用 events.broadcast 通信

  • 新增 类语法 (Class Syntax): Rhino 引擎的 class 语法范围, 内建类型的子类化, 继承 Java 类与接口的写法和限制, 与 JavaAdapter 的关系, 以及严格模式下 Proxy 的 set trap 要返回 true.

  • 更新 Flow 与 运行时 API (Runtime APIs): Node.js, Worker 与 Bun 的 Flow 对象增加 await() 与 sync(timeout), 两者都返回 Promise, 不阻塞脚本线程, 写作 await chain.sync(); 超过 timeout 时以 TIMEOUT 错误拒绝, 流程继续运行, 与 Rhino 相同

  • 更新 OcrOptions 的 profile 与 mergeLine: 补充 PP-OCRv3 的 7 个新语种包, 说明阿拉伯语的阅读顺序与天城文等文字的识别局限.

  • 修复 运行时 API: Node.js 与 Bun 的 zip, files.open 与 files.toFile 的相对路径按脚本的源目录解析, 与 Rhino 相同, 不再指向宿主无法读写的插件私有目录. Node.js 的 engines.myEngine() 增加 hostCwd 属性.

  • 新增 运行时 API: Node.js 与 Bun 的 colors.theme, gallery 与 files.batchRename, 均返回 Promise, 能力与授权各自独立. Node.js 与 Bun 的 speech 增加 diarize, detectLanguage, tag 与 speech.speaker

  • 更新 OcrOptions: Node.js 与 Bun 的 OCR 方法接受与 Rhino 相同的选项, 含义与默认值一致, 包括 mergeLine.

  • 更新 光学字符识别 (OCR) 的 Node.js 与 Bun 识别结果: 带有 extras 属性, 并接受 useOpenCL 选项.

  • 修复 线程 (Threads) 的 threads.pool: maxPoolSize 为 0 (含默认值) 时不限制上限, corePoolSize 可取任意非负整数.

  • 新增 光学字符识别 (OCR) 的识别结果 OcrResult: extras 属性, 可读取引擎附带的 executionProvider 与 quad 等信息; OcrOptions 新增 useCls 选项

  • 更新 OcrOptions 的 variant, profile, useSlim 与 useOpenCL: PP-OCRv3 改用 ONNX Runtime, Paddle Lite 版用 variant: "v3-paddle-lite" 选择, profile 参与插件匹配

  • 更新 用户界面 (UI), 控制台 (Console), 悬浮窗 (Floaty), 万维网 (Web), 终端 (Terminal), 3-Block Compose (Compose), Compose 节点 (ComposeNode), Compose 会话 (ComposeSession), Compose 悬浮窗 (ComposeFloatyWindow), Compose 状态 (ComposeState), WebSocket, InjectableWebView 与 InjectableWebClient 页的运行时支持表: Bun 的 host 客户端现在与 Node.js 共用同一份界面代码, 提供 ui 的内容窗口与窗口成员 (授权 ui.layout), host.floaty 悬浮窗 (新授权 floaty.control, 原始悬浮窗另需 floaty.raw, 触摸穿透另需 floaty.touch), host.web 的 WebSocket (使用 Bun 自带的连接, 无需授权) 与可注入的 WebView (授权 ui.layout), host.terminal 终端会话 (新授权 terminal.control, 不随 shell 授权自动获得), host.console 的 rawInput / input 与 build 配置器 (授权 console.control), compose 的 ComposeError 与节点成员 (授权 ui.compose); 新授权默认关闭, 在插件中心的 Bun 设置里分别开启
