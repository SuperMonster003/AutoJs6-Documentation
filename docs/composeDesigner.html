3-Block Compose 设计器 (Compose Designer)#

3-Block Compose 设计器是 3-Block Compose 插件 (AutoJs6-Plugin-Three-Block-Compose) 自 1.2.0 起内置的可视化界面编辑器. 它在插件自己的进程中运行, 用插件的真实渲染器所见即所得地编辑 compose 脚本的界面树; 保存结果就是普通的 .js 脚本文件, 可以交给 AutoJs6 运行, 也可以在 AutoJs6 编辑器中继续编写逻辑. 本页面自 3-Block Compose 1.2.0 本地开发预览起适用; 插件尚未发布, 此页不表示官方发布.

本页面不是脚本 API. 设计器没有新增任何全局对象或模块, 它读写的脚本与手写的 compose 脚本完全相同. 脚本 API 见 3-Block Compose, 组件, 属性, 插槽与事件见 ComposeComponents.

用途#

  • 从组件面板拖放组件, 在画布上即时看到与 AutoJs6 内一致的渲染结果, 再在属性抽屉中调整属性, 修饰链, 插槽与事件.
  • 维护脚本的界面部分: 设计器只改写界面树和顶层 compose.state 声明, 其它语句原样保留, 因此可以反复在设计器与 AutoJs6 编辑器之间往返.
  • 设计器不执行脚本: 它用 Rhino 解析器解析脚本并用渲染器预览, 事件处理函数不会在画布中触发, 运行要交给 AutoJs6.

入口#

入口 说明
启动器图标 打开设计器首页 (工程列表). 右下角新建工程, 顶部栏进入组件画廊与设置页, 菜单中导入脚本文件. 设置页中的四种启动器图标都指向首页
AutoJs6 编辑器 "更多" 菜单中的 "在 3-Block Compose 设计器中打开". 需要包含该入口的 AutoJs6 6.8.0 构建 (宿主提交 db7e6a1734 之后); 已安装的插件低于 1.2.0 或未安装时不显示
文件管理器 以 3-Block Compose 打开 .js 文件 (application/x-javascript, text/javascript 或 text/plain)

从 AutoJs6 编辑器或文件管理器打开的文件直接在原位置编辑, 不会复制到设计器的工程目录.

工程与文件#

  • 工程就是一个 .js 文件, 保存在插件私有目录 files/designer/projects/ 中, 没有额外的工程描述文件. 新建工程写入一个最小的 compose.mount 模板; 名称重复时自动加 -2, -3 后缀.
  • 导入: 通过系统文件选择器选择脚本, 复制为一个新工程 (记录来源, 不会自动写回来源文件). 导出: 编辑页菜单 "导出到文件" 通过系统文件选择器另存一份.
  • 外部文档: 从 AutoJs6 编辑器或文件管理器打开的文件保存时直接写回原文件. 没有写入权限时 (例如只读授权或只读路径), 保存会把内容另存为一个新工程并提示, 编辑页随即切换到该工程, 原文件保持不变.
  • 草稿: 编辑停顿约 1 秒和离开编辑页时, 当前内容写入 files/designer/drafts/; 进程被结束后重新打开会询问恢复或丢弃草稿. 只有显式保存才写工程文件或原文件.
  • 外部修改: 回到编辑页时, 如果文件已被其它程序改写 (例如 AutoJs6 编辑器刚保存), 本地没有未保存修改时自动重新加载, 否则询问重新加载还是保留本地修改.
  • 插件不申请存储权限. 工程目录只通过插件自己的内容提供器, 在 "在 AutoJs6 编辑器中打开" 与 "导入 AutoJs6 脚本目录" 时按次授权给 AutoJs6, 不暴露其它目录.

编辑页#

区域 内容
顶部栏 撤销, 重做, 保存; 菜单: 承载选项, 问题, 缩放 (75% / 100%), 复制脚本, 在 AutoJs6 中运行, 在 AutoJs6 编辑器中打开, 导入 AutoJs6 脚本目录, 导出到文件, 组件画廊
画布 真实渲染器预览. 逻辑屏幕与画布视口同大, 对应 compose.mount 填满页面的效果; 点按选中节点, 长按拖到一个容器上放手即可移入 (追加为末尾子节点); 选中节点显示边框与 "类型 #key" 标签; 放大后可平移; 亮暗与主题色跟随设置页
大纲 多级折叠的节点树, 与画布选中同步. 每行提供上移, 下移, 删除; 长按拖动到另一节点的上方, 内部或下方可重排或换父, 是否能放入按目标组件的子节点策略判断
属性 选中节点的 key, 目录属性, 快捷属性 (padding, w, h 等), 插槽, 事件与修饰链
组件面板 右下角 "+" 打开, 按组件画廊的分类列出全部可插入组件, 插入到当前选中的容器 (或根节点); 目标不接受子节点时提示

属性抽屉中每个属性有三种状态: 字面量 (布尔, 枚举, 文本样式, 形状, 颜色, 数值, 列表与字符串各有编辑器), 绑定已声明的 compose.state 变量, 或保留为源码表达式 (以代码框显示, 可改回字面量). 事件列表显示处理函数的参数与源码, 可以直接编辑, 应用前做语法检查; 新增事件时生成一个空的处理函数. 修饰链是有序列表, 支持增删, 上下移与逐项参数编辑; 只对特定父容器有效的修饰项按当前父容器过滤.

承载选项对话框切换 compose.mount, compose.floaty 与 compose.dialog, 并按键值编辑它们的选项对象 (值按脚本字面量填写, 例如 true, 320, 'rawText'). 问题对话框列出按组件目录校验出的错误与警告 (未知属性或事件, 值类型与范围, 修饰项作用域, 子节点策略, 重复 key, 契约上限等) 以及画布无法呈现的部分, 点击条目定位到节点.

全部编辑都进入撤销 / 重做历史; 连续修改同一属性合并为一步.

可识别的脚本子集与往返规则#

设计器打开脚本时只解释下面两类顶层语句, 其余顶层语句 (require, 函数与变量定义, 事件注册, 注释等) 按源码范围原样保留, 位置不变:

  1. 顶层 state 声明: var / let / const x = compose.state(初值).
  2. 唯一的一处挂载调用: compose.mount(...), compose.floaty(...) 或 compose.dialog(...), 参数是返回界面树的渲染函数 (function () { return 树; } 或箭头函数) 或直接写出的节点, 可带选项对象; 渲染函数中 return 之前的语句作为渲染前置语句保留.

界面树内可识别: compose.X({属性}, 子节点...) 与子节点数组写法, 字符串子节点 (等价于 compose.Text), 快捷属性与 compose.modifier().a().b() 修饰链, key, 事件属性中的函数表达式 (源码保留), 以及对已声明 state 的 x.value 绑定. 属性值分三态: 字面量 (字符串, 数字, 布尔, null, 数组与对象字面量) 可在属性抽屉中编辑; x.value 识别为绑定; 其它表达式按源码保留, 画布中文本类属性显示其源码, 其它属性不参与预览. 条件或循环生成的子节点同样按源码保留, 画布中显示为占位.

以下情况无法映射, 设计器拒绝打开并给出行列位置: 语法错误, 没有挂载调用, 多处挂载调用, 根节点不是 compose 工厂调用, 渲染函数没有 return, 属性对象使用展开或计算键, 同一属性对象重复出现 children.

保存时按固定格式生成界面部分: 4 空格缩进, 字符串用单引号, 每个子节点独占一行. 设计器生成的脚本再次打开不会产生任何改动; 手写的脚本第一次保存时界面部分会被改写为该格式, 保留的语句与注释不变. TSX 文件不能在设计器中打开, 首版只支持 JavaScript.

与 AutoJs6 的衔接#

编辑页菜单提供四个去向, 都复用 AutoJs6 的公开入口, 需要已安装 AutoJs6; 去向前如有未保存修改会先保存:

去向 行为
在 AutoJs6 中运行 把脚本文本交给 AutoJs6 运行, 与组件画廊的 "运行" 相同
在 AutoJs6 编辑器中打开 以内容 Uri 和读写授权在 AutoJs6 编辑器中打开同一文件; AutoJs6 保存后回到设计器会自动重新加载
导入 AutoJs6 脚本目录 AutoJs6 以文件名把脚本复制到自己的脚本目录
复制脚本 复制到剪贴板

反向交接由 AutoJs6 编辑器发起: "在 3-Block Compose 设计器中打开" 先保存当前文件, 再以读写授权交给设计器; 设计器保存后回到 AutoJs6 编辑器, 编辑器按文件内容是否变化自动重新加载, 存在未保存修改时先询问. 该菜单项需要包含对应入口的 AutoJs6 6.8.0 构建 (宿主提交 db7e6a1734 之后); 其它去向只需要能运行 compose 脚本的 AutoJs6 (宿主提交 f12665ffde 之后).

设计器本身不依赖 AutoJs6: 画布使用插件自带的渲染器, 与脚本在 AutoJs6 内运行时的渲染实现相同.

限制#

  • 不运行脚本: 事件处理函数不会触发, compose.state 绑定在画布中显示初值, 渲染前置语句与条件 / 循环生成的内容只能以占位呈现.
  • 弹层类组件 (AlertDialog, ModalBottomSheet, DropdownMenu, Tooltip) 处于打开状态时在画布中显示为内联卡片, 不弹出真实窗口; Image 的 src 由 AutoJs6 解析, 画布显示占位; AndroidView 显示占位且不能从组件面板插入; Snackbar 是会话命令, 不在面板中.
  • 画布拖拽只能把节点移到目标容器的末尾, 精确位置用大纲拖拽或上下移调整; 修饰链的顺序用上下移调整.
  • 以 file:// 路径打开的文件受系统存储限制, 可能无法读取或写回; 建议通过 AutoJs6 编辑器或文件管理器以内容 Uri 打开.
