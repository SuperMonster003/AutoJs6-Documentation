引擎 (Engines)#

engines 模块用于启动, 查询和停止脚本引擎, 并监听全部脚本引擎的生命周期事件.

engines

执行配置#

execScript, execScriptFile 和 execAutoFile 的 config 参数支持以下属性:

  • [ workingDirectory = engines.myEngine().cwd() ] { string } - 工作目录
  • [ path = engines.myEngine().cwd() ] { string } - workingDirectory 的兼容别名
  • [ delay = 0 ] { number } - 首次执行前的延迟, 单位为毫秒
  • [ interval = 0 ] { number } - 重复执行之间的间隔, 单位为毫秒
  • [ loopTimes = 1 ] { number } - 执行次数. 0 表示持续执行
  • [ arguments = {} ] { object } - 传给新引擎的参数

arguments 可在新引擎中通过 engines.myEngine().execArgv 读取.

[m] execScript#

execScript(name, script, config?)#

  • name { string } - 脚本名称
  • script { string } - JavaScript 源码
  • [ config = {} ] {{
    • workingDirectory?: string;
    • path?: string;
    • delay?: number;
    • interval?: number;
    • loopTimes?: number;
    • arguments?: object;
  • }} - 执行配置
  • returns { ScriptExecution } - 脚本执行对象

在新引擎中执行字符串源码.

let execution = engines.execScript('worker', `
    console.log(engines.myEngine().execArgv.message);
`, {
    arguments: { message: 'hello' },
});
console.log(execution.getId());

[m] execScriptFile#

execScriptFile(path, config?)#

[6.8.0]

  • path { string } - JavaScript 或 Python 文件路径
  • [ config = {} ] { object } - 执行配置
  • returns { ScriptExecution } - 脚本执行对象

在新引擎中执行本地脚本文件. 相对路径按当前脚本运行时路径解析.

从 AutoJs6 6.8.0 开始, 本地 .py 文件由独立的 Python Runtime 插件执行. 插件不可用或已禁用时, 启动将以失败结束, 且不会回退到 JavaScript 引擎.

engines.execScriptFile('./worker.js', {
    workingDirectory: files.cwd(),
    delay: 100,
    loopTimes: 1,
});

[m] execAutoFile#

execAutoFile(path, config?)#

[6.8.0]

  • path { string } - JavaScript 文件路径
  • [ config = {} ] { object } - 执行配置
  • returns { ScriptExecution } - 脚本执行对象

以自动化脚本模式在新引擎中执行 JavaScript 文件. 此方法保留 JavaScript 和原有自动化脚本语义, 并在执行前确保无障碍服务已启动.

此方法拒绝 Python 文件, 不会将 .py 文件交给 Python Runtime 插件. 执行 Python 文件时使用 execScriptFile.

引擎事件#

6.6.3

engines 是一个 EventEmitter. 生命周期事件会发送到当时存在的每个 JavaScript 引擎.

start#

  • engine { ScriptEngine } - 已启动的引擎

脚本开始执行时触发.

engines.on('start', (engine) => {
    console.log(`started: ${engine.getId()}`);
});

finish#

  • engine { ScriptEngine } - 已结束的引擎

脚本正常结束或异常处理完成时触发. 同一次结束随后还会依次触发兼容事件 exit 和 stop.

exit#

  • engine { ScriptEngine } - 已结束的引擎

finish 的兼容事件.

stop#

  • engine { ScriptEngine } - 已结束的引擎

finish 的兼容事件.

exception#

  • engine { ScriptEngine } - 发生异常的引擎
  • error { java.lang.Throwable } - 异常

脚本发生未处理异常时触发. 随后还会触发兼容事件 error.

error#

  • engine { ScriptEngine } - 发生异常的引擎
  • error { java.lang.Throwable } - 异常

exception 的兼容事件.

[m#] ScriptEngine#emit#

emit(eventName, ...args)#

  • eventName { string } - 事件名称
  • ...args { ...any[] } - 事件参数
  • returns { void }

向此引擎的 events 模块异步发送事件.

let execution = engines.execScript('receiver', `
    events.on('message', (value) => console.log(value));
    setInterval(() => {}, 1000);
`);
setTimeout(() => execution.getEngine().emit('message', 'hello'), 100);
