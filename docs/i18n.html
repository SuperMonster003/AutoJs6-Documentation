国际化 (Internationalization)#

i18n 是基于内置 banana-i18n 模块的本地化函数对象. 它从 JSON 文件或 JavaScript 对象加载不同区域设置的消息, 并按当前区域设置完成消息查找和参数替换.

脚本运行时会自动执行 i18n.loadAll() 并将当前区域设置设为 default. 默认消息目录为 i18n; 如果该相对路径不是目录, i18n.getPath 会尝试使用 assets/i18n.

project/
|-- main.js
`-- i18n/
    |-- default.json
    `-- zh-CN.json

i18n/zh-CN.json:

{
  "welcome": "你好, $1!"
}

main.js:

i18n.setLocale('zh-CN');
console.log(i18n('welcome', 'AutoJs6')); // 你好, AutoJs6!

i18n 的消息语法, 复数规则及回退规则由内置 banana-i18n 实现.

[@] i18n#

i18n(key, ...parameters)#

Global

  • key { string } - 消息键
  • ...parameters { ...any[] } - 消息替换参数
  • returns { string } - 本地化消息

按当前区域设置查找并格式化消息. i18n 是可调用对象, 同时包含本章列出的属性和方法.

[p] banana#

READONLY

  • { Object } - 内置 banana-i18n 实例

返回底层本地化实例. 此属性可用于调用 banana-i18n 提供但本章未封装的能力.

[m] setPath#

setPath(relativePath)#

  • relativePath { string } - 消息目录路径
  • returns { void }

设置 i18n.load 和 i18n.loadAll 使用的消息目录. 路径必须在调用时已经是目录, 否则抛出异常.

[m] setLocale#

setLocale(locale)#

  • locale { string } - 区域设置标识
  • returns { void }

设置后续消息查找使用的区域设置.

[m] getFallbackLocales#

getFallbackLocales()#

  • returns { string[] } - 回退区域设置列表

返回当前区域设置对应的回退区域设置列表.

[m] getParser#

getParser()#

  • returns { Object } - banana-i18n 消息解析器

返回底层消息解析器对象.

[m] getPath#

getPath()#

  • returns { string } - 消息目录路径

返回当前消息目录. 当前配置不是目录时, 先尝试将其解析为 assets 下的相对路径; 回退路径存在时会同时更新当前配置.

[m] getLocale#

getLocale()#

  • returns { string } - 当前区域设置标识

返回当前区域设置.

[m] getFinalFallback#

getFinalFallback()#

  • returns { string } - 最终回退区域设置

返回找不到消息时使用的最终回退区域设置. AutoJs6 创建此模块时将其设为 default.

[m] load#

load(messageSource, locale)#

Overload 1/2

  • messageSource { Object } - 消息键值对象
  • locale { string } - 消息所属的区域设置
  • returns { void }

把消息对象加载到底层消息存储.

i18n.load({
    greeting: 'Hello, $1!',
}, 'en');
i18n.setLocale('en');
console.log(i18n('greeting', 'AutoJs6'));

load(messageSource, locale?)#

Overload 2/2

  • messageSource { string } - 区域设置名称或 JSON 文件路径
  • [ locale ] { string } - 消息所属的区域设置
  • returns { void }

从 JSON 文件加载消息.

  • messageSource 不含系统路径分隔符时, 文件解析为 <消息目录>/<messageSource>.json.
  • messageSource 含系统路径分隔符时, 将其作为文件路径解析.
  • 省略 locale 时, 同时使用 messageSource 作为区域设置标识.

文件不存在, 文件不是普通文件或 JSON 解析失败时抛出异常. JSON 解析失败时还会向控制台写入警告.

[m] loadAll#

loadAll()#

  • returns { void }

加载消息目录第一层的全部 .json 文件. 每个文件的不含扩展名部分作为区域设置标识. 此方法不会递归扫描子目录.
