ImGui 绘制列表 (ImguiDrawList)#

运行时支持 Rhino Node.js 主线程 Node.js Worker Bun
入口 ImguiDrawList 对象 - - -
状态 已支持 71 项 不适用 71 项 (仅限 Rhino 引擎), 等价写法: engines.execScript of a Rhino script that opens the window, events.broadcast between the scripts 不适用 71 项 (仅限 Rhino 引擎), 等价写法: engines.execScript of a Rhino script that opens the window, events.broadcast between the scripts 不适用 71 项 (仅限 Rhino 引擎), 等价写法: engines.execScript of a Rhino script that opens the window, events.broadcast between the scripts

各 API 在同一运行时中的入口, 状态与授权一致, 没有差异项.

Node.js 与 Bun 的导入方式, 异步返回值与授权检查见 运行时 API.

ImguiDrawList 在帧内自由绘制, 由 getWindowDrawList, getForegroundDrawList 与 getBackgroundDrawList 返回, 只能在帧内使用. 坐标, 线宽和尺寸的单位是 px, 方法返回绘制列表本身, 可以链式调用. 类型声明中的名称是 ImGui.DrawList.

每个绘制方法另有 PascalCase 别名, 例如 drawList.AddLine 与 addLine 相同.

点的写法见 Point, 颜色的写法见 Color. 折线和多边形每次最多 4096 个点, 大的路径分成多次绘制.

imgui.createWindow(function (ui) {
    ui.withWindow('绘制', null, 0, function () {
        let draw = ui.getWindowDrawList();
        let origin = ui.getWindowPos();
        let x = origin[0];
        let y = origin[1];
        draw.addRectFilled([x + 20, y + 60], [x + 180, y + 140], '#335C8A', 8)
            .addCircle([x + 100, y + 100], 30, '#FFFFFF', 0, 2)
            .addText([x + 30, y + 150], '#FFC107', 'DrawList');
        draw.pathClear()
            .pathLineTo([x + 200, y + 60])
            .pathLineTo([x + 260, y + 140])
            .pathLineTo([x + 200, y + 140])
            .pathStroke('#66BB6A', 2, ui.DrawFlags.Closed);
    });
}, { width: 320, height: 240 });

DrawTextOptions#

addText 的选项.

选项 类型 说明
font number 或 string Fonts 的值, 或 fonts 选项里的字体名.
size number 字体大小, 单位 px, 默认为当前大小.
wrapWidth number 换行宽度, 单位 px, 默认不换行.

DrawPolylineOptions#

addPolyline 的选项.

选项 类型 说明
thickness number 线宽, 默认 1.
closed boolean 或 number 是否连接最后一点和第一点.
flags number DrawFlags 的组合.

DrawImageOptions#

addImage 的选项.

选项 类型 说明
uv0 Point 左上角的纹理坐标, 0..1.
uv1 Point 右下角的纹理坐标, 0..1.
tint Color 与图像相乘的颜色.

DrawImageQuadOptions#

addImageQuad 的选项, 依次是四个角的纹理坐标.

选项 类型 说明
uv1 Point 第一个角的纹理坐标, 0..1.
uv2 Point 第二个角的纹理坐标.
uv3 Point 第三个角的纹理坐标.
uv4 Point 第四个角的纹理坐标.
tint Color 与图像相乘的颜色.

DrawImageRoundedOptions#

addImageRounded 的选项, 另外读取 DrawImageOptions.

选项 类型 说明
flags number 哪些角是圆角: DrawFlags.RoundCorners*, 默认全部.
