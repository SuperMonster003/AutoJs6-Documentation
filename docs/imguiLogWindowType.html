ImGui 日志窗口 (ImguiLogWindow)#

运行时支持 Rhino Node.js 主线程 Node.js Worker Bun
入口 ImguiLogWindow 对象 - - -
状态 已支持 26 项 不适用 26 项 (仅限 Rhino 引擎), 等价写法: engines.execScript of a Rhino script that opens the window, events.broadcast between the scripts 不适用 26 项 (仅限 Rhino 引擎), 等价写法: engines.execScript of a Rhino script that opens the window, events.broadcast between the scripts 不适用 26 项 (仅限 Rhino 引擎), 等价写法: engines.execScript of a Rhino script that opens the window, events.broadcast between the scripts

各 API 在同一运行时中的入口, 状态与授权一致, 没有差异项.

Node.js 与 Bun 的导入方式, 异步返回值与授权检查见 运行时 API.

ImguiLogWindow 是显示日志行的窗口, 带等级着色, 清空, 导出和自动滚底, 由 imgui.logWindow 或 session.logWindow 返回. 继承 ImguiComponent. 类型声明中的名称是 ImGui.LogWindow. 内置示例 log-hud 演示它的用法.

imgui.createWindow(function (ui) {
    ui.withWindow('控制', null, 0, function () {
        if (ui.button('清空日志')) {
            imgui.logWindow('events').clear();
        }
    });
}, { width: 400, height: 360 });

let log = imgui.logWindow('events', {
    title: '事件',
    maxEntries: 200,
    position: imgui.ToastPosition.BottomLeft,
    onExport: function (text) {
        console.log(text);
    },
});
log.info('启动');
log.warn('磁盘空间不足');
log.append('debug', '详情');

LogEntry#

日志窗口的一行.

字段 类型 说明
timestamp number 添加时的 Date.now().
level LogLevel 等级.
text string 文本.

LogWindowOptions#

logWindow 的选项. 尺寸单位 dp, 回调在脚本线程上运行. 另外读取 ComponentOptions.

选项 类型 说明
title string 窗口标题, 默认为 ID.
open boolean 窗口初始是否打开, 默认 true.
autoScroll boolean 是否滚动到新条目, 默认 true.
maxEntries number 保留的条目数, 至少 1, 默认 1000, 最旧的先移除.
entries (any 或 Object)[] 初始条目: 文本, 或 { level, text }.
position ToastPosition 首次位置的锚点. 省略时由 Dear ImGui 放置.
margin number 与锚点的距离, 单位 dp, 默认 12.
width number 首次宽度, 单位 dp, 默认 380.
height number 首次高度, 单位 dp, 默认 260.
flags number WindowFlags 的组合.
clearLabel string 清空按钮的文字.
exportLabel string 导出按钮的文字.
onAppend Function 每个新条目之后调用.
onClear Function 清空之后调用.
onExport Function 由导出按钮和 export() 调用, 参数为 exportText() 的文本和条目的副本.
onClose Function 关闭时调用.

ImguiLogWindow

[p#] entries#

  • { LogEntry[] }

条目, 最旧的在前.

[p#] autoScroll#

  • { boolean }

新条目是否滚动到可见.

[p#] maxEntries#

  • { number }

保留的条目数, 从下一个条目起生效.

[p#] open#

  • { ValueRef }

窗口的关闭按钮: 变为 false 时组件在下一帧关闭.

[m#] append#

log.append(level, text)#

  • level { LogLevel | string } - 等级.
  • text { any } - 文本.
  • returns { ImguiLogWindow }

添加条目. 无法识别的等级算作 log.

[m#] appendLog#

log.appendLog(text, level?)#

Overload 1/2

  • text { any } - 文本.
  • [ level ] { LogLevel | string } - 等级.
  • returns { ImguiLogWindow }

log.appendLog(level, text)#

Overload 2/2

  • level { LogLevel | string } - 等级.
  • text { any } - 文本.
  • returns { ImguiLogWindow }

添加条目, 等级可以放在第一个或第二个参数.

[m#] log#

log.log(text)#

  • text { any } - 文本, 用 String() 转换.
  • returns { ImguiLogWindow }

添加 log 等级的条目.

[m#] clear#

log.clear()#

  • returns { ImguiLogWindow }

移除全部条目.

[m#] exportText#

log.exportText()#

  • returns { string }

把条目转为文本, 每行一个 [时间] [等级] 文本.

[m#] export#

log.export()#

  • returns { string }

与导出按钮相同: 调用 onExport 并返回文本.

[m#] render#

log.render()#

  • returns { ImguiLogWindow }

在帧内立即绘制窗口, 在自动绘制之外再绘制一次.

READONLY

  • { string }

组件 ID.

READONLY

  • { ImguiSession }

组件所属的会话.

[p#] options#

READONLY

  • { Object }

创建时的选项.

[p#] visible#

  • { boolean }

是否绘制, 参阅 ImguiComponent.

[p#] closed#

READONLY

  • { boolean }

是否已关闭.

READONLY

  • { string | null }

关闭原因, 打开期间为 null.

[m#] show#

log.show()#

  • returns { ImguiLogWindow }

重新开始绘制.

[m#] hide#

log.hide()#

  • returns { ImguiLogWindow }

停止绘制, 保留组件.

[m#] toggle#

log.toggle()#

  • returns { ImguiLogWindow }

在 show 与 hide 之间切换.

[m#] close#

log.close(reason?)#

  • [ reason ] { string } - 写入 closeReason 的原因.
  • returns { ImguiLogWindow }

把组件从会话移除.
