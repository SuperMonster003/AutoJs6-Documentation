ImGui 会话 (ImguiSession)#

ImguiSession 表示一个运行中的 ImGui 窗口, 由 imgui.createWindow, launchFloaty, launch, launchPrivileged 与 runExample 返回, 也是渲染回调的第二个参数. 不能直接用 new 创建. 类型声明中的名称是 ImGui.Session.

字段只读 (严格模式下写入抛出 TypeError), 用对应的 setter 修改. 位置和尺寸的单位是 dp, 乘以 density 得到 px. 同一时间只有一个会话, 参阅 会话, Surface 与根窗口.

只能在 Rhino 引擎中使用, Node.js 与 Bun 参阅 在 Node.js / Bun 中使用.

let session = imgui.createWindow(function (ui, current) {
    ui.withWindow('会话', null, 0, function () {
        ui.text('位置 ' + current.x + ', ' + current.y + ' dp');
        if (ui.button('收起')) {
            current.collapse();
        }
    });
}, { width: 280, height: 180 });

session.on('moved', function (event) {
    console.log('移动到 ' + event.x + ', ' + event.y + ' (' + event.source + ')');
});
session.once('closed', function (event, closedSession) {
    console.log('关闭: ' + closedSession.closeReason);
});
session.setPosition(24, 120);

事件#

用 on, once, off 管理监听器, 也可以用 createWindow 的 events 与 onXxx 选项. 监听器在脚本线程上依次运行, 参数为事件对象和会话, 不要阻塞. 事件对象都有 type (事件名), session (会话) 和 timestamp (触发时的 Date.now()), 下表是各事件另有的字段. 载荷中的位置和尺寸单位是 dp.

事件 触发时机 载荷
ready 第一帧可以绘制 SessionReadyEvent
surfaceRestored Surface 丢失后恢复 SessionReadyEvent
moved 悬浮窗移动 SessionMovedEvent
resized 悬浮窗大小改变 SessionResizedEvent
collapsed 收起到悬浮按钮 SessionCollapsedEvent
expanded 从悬浮按钮恢复 SessionExpandedEvent
closed 会话关闭 SessionClosedEvent
configurationChanged 显示配置改变 SessionConfigurationEvent
touchableChanged 触摸模式或可触摸区域改变 SessionTouchableEvent
moreTouchChanged setMoreTouch 生效 SessionMoreTouchEvent
alphaChanged 窗口不透明度改变 SessionAlphaEvent
secureChanged 安全标志改变 SessionSecureEvent
idle 帧循环进入空闲帧率 SessionIdleEvent
active 帧循环回到全速 SessionActiveEvent
back Activity 模式下按返回键 SessionBackEvent
fontScaleChanged 会话的字体缩放改变 SessionFontScaleEvent
error 回调抛出异常 SessionErrorEvent

ready 在 createWindow 返回之前同步触发. 插件 1.18.0 及更早版本中 session.on('ready', ...) 收不到它, 这些版本请用 createWindow 的 onReady / events 选项.

SessionReadyEvent#

Surface 可以绘制: 第一次是 ready, 恢复时是 surfaceRestored.

字段 类型 说明
restored boolean Surface 是否在丢失后恢复.
mode WindowMode 窗口模式.
backend string 或 null 特权会话请求的后端, 其他情况为 null.
width number 窗口宽度.
height number 窗口高度.

SessionMovedEvent#

字段 类型 说明
x number 新的左边缘.
y number 新的上边缘.
oldX number 之前的左边缘.
oldY number 之前的上边缘.
source string 移动来源: drag, api, configuration 等.

SessionResizedEvent#

字段 类型 说明
width number 新的宽度.
height number 新的高度.
oldWidth number 之前的宽度.
oldHeight number 之前的高度.
source string 改变来源: api, content, configuration 等.

SessionConfigurationEvent#

显示配置改变. 密度改变后窗口保持 dp 尺寸和位置, 字体和样式尺寸随之缩放; 系统字体大小改变只缩放字体. imgui.launch 的窗口改为以 closeReason 为 configuration-changed 关闭, 因为 Android 会重建它的 Activity. 帧循环每秒检查 4 次, 在两帧之间应用变化.

字段 类型 说明
width number 屏幕宽度.
height number 屏幕高度.
oldWidth number 之前的屏幕宽度.
oldHeight number 之前的屏幕高度.
orientation 'landscape' 或 'portrait' 屏幕方向.
density number 显示密度.
oldDensity number 之前的显示密度.
fontScale number 系统字体缩放.
oldFontScale number 之前的系统字体缩放.

SessionFontScaleEvent#

字段 类型 说明
scale number 新的缩放值, 0.5..3.
oldScale number 之前的缩放值.
source 'pinch' 或 'api' 改变来源.

SessionCollapsedEvent#

字段 类型 说明
button ImguiFloatingButton 或 null 显示的悬浮按钮, 没有时为 null.
fps number 收起时的帧率.

SessionExpandedEvent#

字段 类型 说明
x number 左边缘.
y number 上边缘.
width number 宽度.
height number 高度.

SessionClosedEvent#

字段 类型 说明
reason string closeReason 的值.

SessionTouchableEvent#

字段 类型 说明
mode TouchMode 触摸模式.
touchable boolean Surface 是否接收触摸.
interactiveRegionCount number TouchMode.Auto 下的可触摸矩形数.

SessionMoreTouchEvent#

字段 类型 说明
enabled boolean 新的状态.

SessionAlphaEvent#

字段 类型 说明
alpha number 新的不透明度, 0..1.

SessionSecureEvent#

字段 类型 说明
secure boolean 新的状态.

SessionIdleEvent#

字段 类型 说明
fps number 空闲帧率.
idleDelay number 经过的无输入时间, 单位 ms.

SessionActiveEvent#

字段 类型 说明
fps number 全速帧率.
reason 'input' 或 'screen' 或 'api' 结束空闲的原因.

SessionBackEvent#

Activity 模式 (imgui.launch) 的返回键. 监听器运行后, 除非有监听器调用 preventDefault(), 否则会话以 closeReason 为 back 关闭. 显示中的软键盘优先处理返回键. 悬浮窗没有这个事件.

字段 类型 说明
defaultPrevented boolean 是否有监听器调用过 preventDefault().
preventDefault Function 保持会话打开.

SessionErrorEvent#

渲染回调 (phase 为 render) 或事件回调 (phase 为 event) 抛出异常. 错误也用 console.error 打印, 连续相同的错误只打印一次. 没有 error 监听器时渲染错误关闭会话 (closeReason 为 render-error); 有监听器时跳过这一帧余下的部分, 会话继续, 在监听器里调用 session.close() 可以结束. 高层组件绘制失败只关闭该组件. error 监听器自己抛出的异常只打印.

字段 类型 说明
error any 抛出的值.
phase 'render' 或 'event' 抛出的位置.
frame number 出错前已显示的帧数.
message string error.message, 或转为字符串的错误.
event string 抛出异常的事件名 (phase 为 event), 悬浮按钮回调为 buttonClick.
component ImguiComponent 绘制时抛出异常的高层组件 (phase 为 render).
button ImguiFloatingButton 回调抛出异常的悬浮按钮 (事件 buttonClick).

[m#] capture#

session.capture(options?)#

  • [ options ] { CaptureOptions } - 选项, 参阅 CaptureOptions.
  • returns { CapturedImage } - 窗口的图像, 需要 recycle().

返回窗口最后显示的一帧, 是 images 模块的图像, 可以传给 images.save 等函数. 尺寸单位 px (窗口尺寸乘密度, 或 region), 没有绘制的地方是透明的. 用完调用 recycle(), 脚本结束时释放其余的图像.

悬浮窗和 Activity 窗口用 PixelCopy 读取, 最多等 5 秒, 也可以在渲染回调中调用, 得到上一帧. 特权窗口用 glReadPixels 读取, 只能在两帧之间调用, 例如放进 setTimeout(fn, 0), 在渲染回调中调用会抛出 Error. 窗口已收起, 已关闭或还没有显示过帧时抛出 Error.

let session = imgui.createWindow(function (ui) {
    ui.withWindow('截图', null, 0, function () {
        ui.text('Hello');
    });
}, { width: 240, height: 120 });

setTimeout(function () {
    let image = session.capture({ region: { width: 120 } });
    console.log(image.getWidth() + ' x ' + image.getHeight() + ' px');
    image.recycle();
}, 500);
