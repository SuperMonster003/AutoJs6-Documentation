定时器 (Timers)#

timers 模块提供当前脚本进程内的事件循环定时器, 并提供一组与 workManager 兼容的持久化任务入口.

脚本内定时器是单线程的. 当前脚本长时间阻塞时, 回调只能在事件循环恢复后执行.

timers

[m] setTimeout#

setTimeout(callback, delay?, ...args)#

Global

  • callback { Function } - 定时器到期时执行的函数
  • [ delay = 1 ] { number } - 等待时间, 单位为毫秒
  • ...args { ...any[] } - 传给回调的参数
  • returns { number } - 定时器 ID

创建单次定时器.

Global

  • callback { Function } - 每次定时器到期时执行的函数
  • [ delay = 1 ] { number } - 间隔时间, 单位为毫秒
  • ...args { ...any[] } - 传给回调的参数
  • returns { number } - 定时器 ID

创建重复定时器.

[m] setIntervalExt#

setIntervalExt(listener, interval?, timeoutOrCondition?, callback?)#

  • listener { Function } - 每次间隔到期时执行的函数
  • [ interval = 200 ] { number } - 间隔时间, 单位为毫秒
  • [ timeoutOrCondition ] { number | Function } - 总超时时间或结束条件
  • [ callback ] { Function } - 结束时执行的回调
  • returns { number } - 首次调度的定时器 ID

重复执行 listener. 第 3 个参数为正数时, 从调用开始经过指定毫秒数后结束; 为函数时, 每次执行 listener 后计算结束条件. 条件结果不是 null, undefined 或 false 时结束, 并将该结果传给 callback.

[m] keepAlive#

keepAlive(timeout?)#

Global

  • [ timeout = 0 ] { number } - 保持脚本存活的时间, 单位为毫秒
  • returns { number } - 定时器 ID

timeout 大于 0 时创建对应时长的空定时器. 省略或不大于 0 时创建每 10000 毫秒执行一次的空定时器, 使脚本持续运行.

loop()#

Global ABANDONED

  • returns { void }

此兼容方法不再提供事件循环控制功能, 调用时仅输出废弃警告.
