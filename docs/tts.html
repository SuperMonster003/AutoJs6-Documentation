文本转语音 (TTS)#

tts 模块用于通过 Android 文本转语音引擎播放文本, 插入静音, 合成音频文件, 查询引擎和语音, 以及监听单次任务的执行事件.

tts 与 $tts 指向同一个可调用模块对象.

tts 服务属于当前脚本运行时. 脚本退出时, 未完成的请求会停止, 相关引擎资源会释放.

Android 17 的 后台音频限制 需要结合实际 TTS 引擎判断. 此模块通过 Android TextToSpeech 委托所选引擎合成和播放, 实际音频可能来自引擎进程; 宿主前台服务状态不能单独代表引擎的播放资格. 播放无声时, 检查引擎, 语音数据与系统音量, 并从可见应用界面重试. 合成成功或任务完成事件不等于设备实际发声. synthesizeToFile 只合成文件, 不以宿主能否后台播放作为执行条件.

tts

[@] tts#

tts(text, options?)#

6.8.0 Async Overload [1-2]/2

  • text { string } - 待朗读文本
  • [ options = {} ] { TtsOptions } - 朗读选项
  • returns { Promise } - 兑现值为 TtsResult

朗读文本.

此调用与 tts.speak(text, options?) 等价.

tts('Hello from AutoJs6').then((result) => {
    console.log(result.status);
});

[p] maxInputLength#

6.8.0

  • { number }

初始值为 3999, 表示单次 Android 文本转语音请求的安全文本长度上限, 单位为 UTF-16 code unit.

speak 默认会将更长文本拆分为多个请求, 因此此值不是朗读方法允许的总文本长度上限.

[p] maxSynthesisFileSize#

6.8.0

  • { number }

初始值为 536870912, 表示文件合成结果的最大字节数, 即 512 MiB.

[p] QUEUE_FLUSH#

6.8.0

  • { string }

初始值为 'flush', 表示替换当前队列的队列模式.

[p] QUEUE_ADD#

6.8.0

  • { string }

初始值为 'add', 表示追加到当前队列的队列模式.

[m] speak#

speak(text, options?)#

6.8.0 Async Overload [1-2]/2

  • text { string } - 待朗读文本
  • [ options = {} ] { TtsOptions } - 朗读选项
  • returns { Promise } - 兑现值为 TtsResult

将文本加入文本转语音服务.

默认队列模式为 flush, 会替换等待中的任务. 文本默认按最多 3999 个 UTF-16 code unit 自动拆分.

输入文本不能为空白, 总长度不能超过 1000000 个 UTF-16 code unit.

[m] utterance#

utterance(text, options?)#

6.8.0 Async Overload [1-2]/2

        console.log(info.id);

    .on('done', (result) => {
        console.log(result.duration);
    });

[m] synthesize#

synthesize(text, path, options?)#

6.8.0 Async Overload [1-2]/2

  • text { string } - 待合成文本
  • path { string } - 输出文件路径
  • [ options = {} ] { TtsFileOptions } - 合成选项
  • returns { Promise } - 兑现值为 TtsResult

将文本合成为音频文件.

synthesize 也可写作 synthesizeToFile.

文件合成只执行一次平台请求, 文本长度不能超过 3999 个 UTF-16 code unit. autoSplit 不会拆分文件输出.

默认先写入临时文件, 成功后再原子替换目标文件. overwrite 为 false 时要求严格的原子不替换发布, 某些共享存储文件系统不支持该操作并会使 Promise 拒绝.

tts.synthesize('Saved speech', './speech.wav').then((result) => {
    console.log(result.path);
});

选项#

TtsOptions#

每次调用中未指定的选项继承 defaults 的当前值. 初始默认值如下:

  • [ engine = null ] { string | null } - 引擎包名, null 表示系统默认引擎
  • [ locale = null ] { string | null } - IETF 语言标签
  • [ voice = null ] { string | null } - 语音名称
  • [ rate = 1 ] { number } - 语速, 范围为 0.1..4
  • [ pitch = 1 ] { number } - 音高, 范围为 0.1..4
  • [ volume = 1 ] { number } - 音量, 范围为 0..1
  • [ pan = 0 ] { number } - 左右声道位置, 范围为 -1..1
  • [ queue = 'flush' ] { string | number } - 队列模式
  • [ autoSplit = true ] { boolean } - 是否自动拆分长文本
  • [ offlineOnly = false ] { boolean } - 是否仅选择离线语音
  • [ audioEvents = false ] { boolean } - 是否接收音频数据事件
  • [ usage = 'media' ] { string } - Android 音频用途
  • [ timeout = 'auto' ] { number | 'auto' | null } - 任务超时, 单位为毫秒
  • [ parameters = {} ] { Object } - 传给文本转语音引擎的额外参数

兼容属性名称:

  • locale: language, lang.
  • rate: speechRate.
  • autoSplit: split.
  • offlineOnly: offline.
  • audioEvents: emitAudio.
  • usage: audioUsage.
  • timeout: timeoutMillis, timeoutMs.
  • parameters: params.

locale 和 voice 不能在同一组选项中同时指定为非 null.
队列模式可使用 flush, replace, add, enqueue, append, 0 或 1.
音频用途支持 media, accessibility, assistant, navigation, alarm, notification 和 voiceCommunication.

timeout 为 0 时禁用任务超时.
timeout 为 null 或 auto 时根据操作类型和文本长度自动计算.
其他超时值必须是 1000..86400000 范围内的整数.

parameters 最多包含 32 项. 属性值只能是字符串, 布尔值或有限数值. rate, engine, pitch, volume, pan 和 utteranceId 等已有专用选项的名称不能重复用于 parameters.

未知选项会使调用抛出异常.

TtsFileOptions#

TtsFileOptions 包含全部 TtsOptions, 并增加:

  • [ overwrite = true ] { boolean } - 是否替换已存在的目标文件
  • [ createDirectories = true ] { boolean } - 是否创建缺失的父目录

mkdirs 可作为 createDirectories 的别名.

TtsEngineQueryOptions#

  • [ engine ] { string | null } - 引擎包名

TtsVoiceFilter#

  • [ engine ] { string | null } - 引擎包名
  • [ locale ] { string | null } - IETF 语言标签
  • [ offlineOnly = false ] { boolean } - 是否仅返回离线语音
  • [ installedOnly = false ] { boolean } - 是否仅返回已安装语音

兼容属性名称:

  • locale: language, lang.
  • offlineOnly: offline.
  • installedOnly: installed.

返回对象#

TtsResult#

  • id { string } - 任务 ID
  • operation { 'speech' | 'silence' | 'file' } - 操作类型
  • status { 'done' } - 完成状态
  • engine { string | null } - 实际使用的引擎包名
  • requestedEngine { string | null } - 请求使用的引擎包名
  • voice { string | null } - 实际使用的语音名称
  • locale { string | null } - 实际使用的语言标签
  • usage { string | null } - 实际音频用途
  • chunks { number } - 平台请求块数量
  • characters { number } - 输入文本长度
  • duration { number } - 从开始到完成的时长, 单位为毫秒
  • path { string | null } - 文件合成目标路径

TtsReadyInfo#

  • state { 'ready' } - 就绪状态
  • engine { string } - 实际引擎包名
  • requestedEngine { string | null } - 请求使用的引擎包名
  • defaultEngine { string | null } - 系统默认引擎包名
  • voice { TtsVoiceInfo | null } - 最近选择的语音
  • locale { string | null } - 最近选择的语言标签

TtsEngineInfo#

  • name { string } - 引擎包名

TtsUtterance#

  • extends { EventEmitter }

TtsUtterance 表示一个可监听和停止的文本转语音任务. 它不能由脚本直接构造.

它继承 EventEmitter 的 addListener, eventNames, listenerCount, listeners, prependListener, prependOnceListener, removeAllListeners, removeListener 和 setMaxListeners 等方法.

TtsUtterance 事件#

事件 监听器参数 说明
queued info { TtsQueuedEvent } 任务已进入服务
start info { TtsStartEvent } 任务开始执行
chunk info { TtsChunkEvent } 开始朗读一个文本块
range info { TtsRangeEvent } 引擎报告当前文本范围
synthesis info { TtsSynthesisEvent } 引擎报告音频格式
audio info { TtsAudioEvent } 引擎提供音频数据
done result { TtsResult } 任务正常完成
stop info { TtsStopEvent } 任务停止
error error { TtsError } 任务失败
cancelled info { TtsStopEvent } 任务被取消

调用任务的 stop 或 cancel 后, 会依次触发 stop 和 cancelled.
由队列替换导致的平台停止会触发 stop, 但不会触发 cancelled.

只有 audioEvents 为 true 时才接收 audio 事件.

TtsQueuedEvent#

  • id { string } - 任务 ID
  • operation { 'speech' | 'silence' | 'file' } - 操作类型
  • queue { 'flush' | 'add' } - 队列模式
  • chunks { number } - 请求块数量

TtsStartEvent#

  • id { string } - 任务 ID
  • operation { 'speech' | 'silence' | 'file' } - 操作类型
  • voice { string | null } - 语音名称
  • locale { string | null } - 语言标签
  • chunks { number } - 请求块数量

TtsChunkEvent#

  • id { string } - 任务 ID
  • index { number } - 当前块序号
  • count { number } - 块总数
  • start { number } - 当前块在原文本中的起始索引
  • end { number } - 当前块在原文本中的结束索引

TtsRangeEvent#

  • id { string } - 任务 ID
  • start { number } - 当前范围在原文本中的起始索引
  • end { number } - 当前范围在原文本中的结束索引
  • frame { number } - 引擎报告的音频帧位置
  • chunk { number } - 当前块序号

TtsSynthesisEvent#

  • id { string } - 任务 ID
  • sampleRate { number } - 采样率, 单位为 Hz
  • encoding { 'pcm_8_bit' | 'pcm_16_bit' | 'pcm_float' | 'unknown' } - 音频编码
  • channels { number } - 声道数
  • chunk { number } - 当前块序号

TtsAudioEvent#

  • id { string } - 任务 ID
  • data { ByteArray } - 音频字节数组
  • chunk { number } - 当前块序号

TtsStopEvent#

  • id { string } - 任务 ID
  • operation { 'speech' | 'silence' | 'file' } - 操作类型
  • status { 'stopped' } - 停止状态
  • reason { string } - 停止原因

常见停止原因为 cancelled, flushed, interrupted, stopped 或 reset.

TtsError#

  • code { string } - TTS 错误代码
  • message { string } - 错误消息
  • errorCode { number | null } - Android 文本转语音错误码
  • reason { string | undefined } - 中断原因

只有中断错误包含 reason.
