计划任务兼容接口 (WorkManager)#

workManager 模块用于创建, 查询和移除持久化计划任务.

workManager, $workManager, work_manager 与 $work_manager 指向同一个模块对象.

此模块是面向脚本的 Auto.js Pro 兼容接口, 不是 androidx.work.WorkManager 的 JavaScript 映射.

workManager 与 tasks 使用同一任务数据库, 但两者的返回约定不同:

  • workManager 的创建操作始终同步返回任务对象.
  • workManager 的移除操作返回数据库操作结果.
  • tasks 的部分操作支持回调或异步执行, 移除操作返回被移除的任务对象.

workManager

[m] addDailyTask#

addDailyTask(options)#

6.8.0

  • options { DailyTaskOptions } - 每日任务选项
  • returns { TimedTask } - 已保存的定时任务

创建每天运行的定时任务.

let task = workManager.addDailyTask({
    path: './daily.js',
    time: '08:30',
});
console.log(task.id);

[m] addDisposableTask#

addDisposableTask(options)#

6.8.0

  • options { DisposableTaskOptions } - 单次任务选项
  • returns { TimedTask } - 已保存的定时任务

创建仅运行一次的定时任务.

可指定绝对时间, 也可指定从当前时刻开始计算的倒计时.

let task = workManager.addDisposableTask({
    path: './later.js',
    after: {
        minutes: 10,
    },
});
console.log(task.id);

任务选项#

workManager 会忽略创建选项中的 callback, condition, isAsync 和 async, 并同步返回任务对象.

所有脚本路径都通过当前脚本运行时的文件路径规则解析.

TimedTaskExecutionOptions#

定时任务共享以下执行选项:

  • path { string } - 待执行脚本的路径
  • [ delay = 0 ] { number } - 脚本执行前的延迟, 单位为毫秒
  • [ interval = 0 ] { number } - 循环执行间隔, 单位为毫秒
  • [ loopTimes = 1 ] { number } - 脚本循环执行次数

RepeatEndOptions#

每日和每周任务可使用以下重复结束选项:

  • [ endMode = 'forever' ] { number | string } - 结束模式
  • [ untilDate ] { number | Date | string } - 截止日期
  • [ times ] { number } - 总运行次数

endMode 也可写作 ends, end 或 repeatEnd.

结束模式字符串支持:

  • 永久运行: forever, always, never.
  • 截止日期: untilDate, until, date.
  • 固定次数: count, times, number, numberOfEvents, forNumberOfEvents.

结束模式数值 0, 1 和 2 分别表示永久运行, 截止日期和固定次数.

untilDate 也可写作 until 或 endDate.
times 也可写作 endCount. 显式选择固定次数模式时还可写作 count.

DailyTaskOptions#

  • path { string } - 待执行脚本的路径
  • [ time = 当前本地时间 ] { number | Date | string } - 每日运行时间
  • [ delay = 0 ] { number } - 脚本执行前的延迟, 单位为毫秒
  • [ interval = 0 ] { number } - 循环执行间隔, 单位为毫秒
  • [ loopTimes = 1 ] { number } - 脚本循环执行次数
  • [ endMode = 'forever' ] { number | string } - 重复结束模式
  • [ untilDate ] { number | Date | string } - 截止日期
  • [ times ] { number } - 总运行次数

date 可作为 time 的别名.

时间字符串由 org.joda.time.LocalTime.parse 解析, 例如 '08:30'.

WeeklyTaskOptions#

  • path { string } - 待执行脚本的路径
  • [ time = 当前本地时间 ] { number | Date | string } - 每周运行时间
  • [ daysOfWeek = 当前本地星期 ] { number[] | string[] } - 每周运行日
  • [ delay = 0 ] { number } - 脚本执行前的延迟, 单位为毫秒
  • [ interval = 0 ] { number } - 循环执行间隔, 单位为毫秒
  • [ loopTimes = 1 ] { number } - 脚本循环执行次数
  • [ endMode = 'forever' ] { number | string } - 重复结束模式
  • [ untilDate ] { number | Date | string } - 截止日期
  • [ times ] { number } - 总运行次数

date 可作为 time 的别名.

星期字符串支持完整英文名称, 3 字母英文缩写, 以及中文数字名称.
星期数值支持 0..6 和 1..7, 其中 0 或 7 表示星期日.

DisposableTaskOptions#

  • path { string } - 待执行脚本的路径
  • [ time = 当前本地日期和时间 ] { number | Date | string } - 绝对运行时间
  • [ after ] { number | DurationOptions } - 从当前时刻开始计算的延迟
  • [ delay = 0 ] { number } - 脚本执行前的延迟, 单位为毫秒
  • [ interval = 0 ] { number } - 循环执行间隔, 单位为毫秒
  • [ loopTimes = 1 ] { number } - 脚本循环执行次数

date 可作为 time 的别名.

after 也可写作 countdown, timeOffset, duration 或 runAfter.
延迟为数值时, 单位为毫秒. 延迟必须大于 0.

当绝对时间和延迟同时存在时, 延迟优先.

DurationOptions#

  • [ days = 0 ] { number } - 天数
  • [ hours = 0 ] { number } - 小时数
  • [ minutes = 0 ] { number } - 分钟数
  • [ seconds = 0 ] { number } - 秒数
  • [ milliseconds = 0 ] { number } - 毫秒数

各字段必须为非负整数, 总时长必须大于 0.

字段还支持以下短名称:

  • days: day, d, delayDays.
  • hours: hour, hr, h, delayHours.
  • minutes: minute, min, m, delayMinutes.
  • seconds: second, sec, s, delaySeconds.
  • milliseconds: millisecond, millis, ms, delayMillis.

IntentTaskOptions#

  • path { string } - 待执行脚本的路径
  • [ action ] { string } - Intent action
  • [ category ] { string } - Intent category
  • [ dataType ] { string } - Intent MIME 类型
  • [ isLocal = false ] { boolean } - 是否使用本地广播

local 可作为 isLocal 的别名.

AutoJs6 启动事件对应的 action 会默认使用本地广播. 显式设置 isLocal 或 local 时, 显式值优先.

TimedTaskQueryOptions#

  • [ path ] { string } - 脚本路径过滤条件

IntentTaskQueryOptions#

  • [ path ] { string } - 脚本路径过滤条件
  • [ action ] { string } - Intent action 过滤条件

返回对象#

TimedTask#

workManager 的定时任务对象由 tasks 模块共用的 org.autojs.autojs.timing.TimedTask 提供.

常用公开属性包括 id, scriptPath, millis, repeatMode, timeFlag, scheduled, endMode 和 endValue.

IntentTask#

workManager 的 Intent 任务对象由 tasks 模块共用的 org.autojs.autojs.timing.IntentTask 提供.

常用公开属性包括 id, scriptPath, action, category, dataType 和 local.
